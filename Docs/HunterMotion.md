# 사냥꾼 스킬 모션

스킬별 완성 일러스트 교체를 없애고 같은 모델을 사용하는 4행 × 6열 키 포즈 시트를 재생합니다. 검은 모자·해골 장식·깃털·금발과 땋은 머리·붉은 스카프·검정/금색 코트의 정체성을 유지하며, 선화와 컬러 블록을 단순한 카툰 셀 표현으로 통일했습니다. 기존 원본 그림은 보관합니다.

`Previews/HunterMotionGuide.html`은 정상 속도/저속 재생, 시간 탐색, 키 포즈 배열 및 확인용 공격 범위를 제공합니다. 같은 폴더의 `HunterMotionAtlas.png`, `HunterMotionMetadata.js`가 필요합니다. 스킬당 6개 키 포즈와 이동·도약·반동을 조합한 애니메이션입니다. 별도 이동 시트에는 네 방향 원화와 좌우 반전을 사용하는 32개 포즈를 연결했습니다. [이동 애니메이션 안내](Locomotion.md)를 참고하세요.

`Previews/HunterMotionGuideStandalone.html`은 이번 빌드의 이미지·좌표 데이터를 내장한 단일 파일 배포본입니다. 외부 파일이나 서버 없이 브라우저에서 열 수 있도록 구성했습니다. 자동 브라우저 미리보기는 로컬 파일 URL 보안 정책으로 차단되어 실행 화면 검사는 Unity 플레이어 캡처로 진행했고, 가이드 스크립트는 구문 검사를 완료했습니다.

| 동작 | 시전 / 복귀 종료 | 실제 피해 시점 | 위치와 범위 |
|---|---|---|---|
| 베어 가르기 | 0.48초 | 0.11–0.30초 | 최대 2.85m 돌진, 주변 1.6m, 같은 적에게 한 번 |
| 내려찍기 | 2.00초 | 0.80초 / 1.05초 | 중심 고정, 반경 2.3m / 3.2m, 표시만 최대 0.95m 도약 |
| 원 샷 | 0.45초 | 0.12초 | 입력 당시 조준 방향, 전방 4m / 폭 1.6m |
| 주변 난사 | 2.00초 | 0.20초 간격 다섯 번 | 주변 반경 5m |

기본 공격에도 짧은 준비 동작을 둡니다. 단검은 약 0.065초, 리볼버는 약 0.078초 뒤 공격이 발생합니다. 리볼버의 탄약은 실제 발사 시 소비하며 그 전에 회피·태그로 취소하면 발사하지 않습니다. 콤보는 여전히 실제 적중으로만 쌓이고 4타 까마귀 연계가 유지됩니다. 스킬 쿨다운은 복귀 종료 또는 허용된 취소부터 8초입니다.

## Unity 구성

- `HunterMotion.cs`: 동작과 피해가 공유하는 초 단위 타이밍, 프레임 선택, 착지 높이, 시트 로더.
- `Player.cs`: 준비/활성/복귀 진행, 입력 방향 보관, 지연 피해, 회피 취소, 공격 콜리전.
- `SkillEffects.cs`: 캐릭터와 분리된 셀 색상의 베기 궤적·총구 섬광·충격파.
- `PaperWorld.cs`: 2.5D 카드에 원본 SpriteRenderer의 재질을 전달합니다.
- `Assets/Resources/Motion/HunterSkills.png`: 채택된 원본 시트. RGB 마젠타 배경은 `CartoonAtlas.shader`로 화면에서 제거합니다. 파일에 투명 알파가 들어 있다고 가정하지 않습니다.
- `MotionSetup.cs`: 읽기 가능한 비압축/보간 텍스처 설정, 24개 셀·발 기준점·재질 검증, 가이드용 메타데이터 출력.

모든 프레임은 첫 Idle의 실제 그림 높이를 기준으로 **동일한 스케일**을 사용합니다. 화면에서 서 있는 크기는 기존 1.9 단위를 유지하며, 몸을 숙인 포즈까지 같은 키로 늘리지 않습니다. 각 셀 아래쪽 발/옷자락에서 기준점을 구해 공격 무기의 길이가 캐릭터 중심을 흔들지 않도록 합니다. 좌우 반전을 지원하고 실제 타격 방향은 입력 방향을 사용합니다. 이 시트는 우향 3/4 시점 키 포즈이므로 위·아래 방향별 전용 포즈 시트는 후속 제작 범위입니다.

`--motion-test` 실행 검증은 준비 구간의 무피해, 돌진 거리/중복 피해 방지, 착지 타이밍, 총격 조준, 난사의 다섯 타격, 취소와 탄약, 일시정지, 4타 까마귀 연계, 동일 스케일을 검사하고 실제 게임 화면의 24개 키 포즈를 `Logs/motion-행-열.png`로 저장합니다. `--smoke-test`는 기존 던전·전투·Timeline 통합 검증입니다.

최종 확인: Windows 빌드 성공, 모션 62개 검증 통과, 기존 통합 검증 2097개 통과(30개 방 / 50웨이브). 총구 높이 수정 후 실제 플레이어에서 재검증했습니다. 단일 파일 모션 가이드는 구문 검사 완료이며, 자동 브라우저 화면 검토는 로컬 파일 URL 정책에 의해 차단되었습니다.
