# 몬스터 도감

최종 갱신일: 2026-10-28

일반 / 엘리트 / 보스 몬스터의 행동과 현재 구현 정보를 기록한다. 수치는 별도 표시가 없는 한 유니티 월드 단위와 초 단위이며, 프리팹의 저장값을 기준으로 한다. 씬 인스턴스에서 별도로 변경한 값은 다를 수 있다.

## 등록 및 갱신 규칙

- 새 몬스터를 처음 제작할 때 일반 / 엘리트 / 보스 중 어디에 넣을지 사용자에게 묻고, 정해진 분류에 등록한다. 이미 지정한 분류는 다시 묻지 않는다.
- 등록된 모든 몬스터는 수정 작업마다 도감도 최신화할지 사용자에게 묻는다. 동의한 경우에만 변경 사항과 갱신일을 반영한다. 갱신을 명시적으로 요청한 작업은 재확인하지 않는다.
- 각 항목은 이름, 분류, 행동, 능력치, 구현 상태, 관련 파일, 변경 이력을 기록한다. 임시값과 확정 조건을 구별한다.
- 작업 지침은 프로젝트 루트의 `AGENTS.md`에도 기록되어 있다.

## 공통 스킬 분류

### 슬로우 무브먼트 스킬 — 2026-10-28 추가

스킬 사용 중 일반 이동을 허용하되 이동 속도를 줄이는 공통 분류다. 각 공격 부품은 `ISlowMovementSkill`을 구현해 현재 상태의 배율을 제공하고, `EnemyBasicBrain`이 이동 부품에 전달하는 외부 속도 배율에 이를 한 번 곱한다. 사용 중이 아니면 배율 1로 복구한다.

| 스킬 | 감속 적용 구간 | Inspector 배율 | 초기값 |
| --- | --- | --- | --- |
| Cowboy 올가미 | 준비·비행·회수 (`Spin`, `LassoOut`, `LassoReturn`) | `Cowboy Attack → Lasso Move Multiplier` | 0.35 |
| Robe Man 독병 | 조준·투척 후딜 (`Aim`, `ThrowRecovery`) | `Robe Man Attack → Poison Move Multiplier` | 0.35 |

- 배율 범위는 0~1이다. 0은 이동 정지, 0.35는 기본 속도의 35%, 1은 감속 없음이다. Inspector 변경은 다음 일반 이동 갱신에 반영된다.
- 최종 이동 속도는 `이동 부품의 Speed × 외부 이동 배율 × 스킬 배율`이다. 이동 부품의 정지 거리·후퇴·장애물 규칙은 그대로 적용되므로 감속 구간이라고 항상 이동하는 것은 아니다.
- 공격 `Tick()`이 이동 정지를 요청하는 사격 준비·근접 공격·기절 등의 상태는 정지가 우선한다. 비활성화한 공격 부품의 스킬 배율은 적용하지 않는다.
- 독병의 고정 조준과 근접 공격 제한은 유지한다. 이미 던진 독병이나 남아 있는 독 위험구역의 수명은 시전자의 감속을 연장하지 않는다.
- Cowboy의 일반 이동은 `EnemyKeepDistanceMovement`로 통합했다. 기존 속도 2.2, 정지 거리 6, 후퇴 없음·분리 이동 없음 설정을 유지하며 `CowboyMovement`는 제거했다. Robe Man은 `EnemyChaseMovement`를 유지한다.
- 관련 공통 파일: `Assets/Scripts/Enemy/ISlowMovementSkill.cs`, `Assets/Scripts/Enemy/EnemyBasicBrain.cs`. 별도의 스킬 컴포넌트를 추가할 필요는 없다.

공통 변경 이력: **2026-10-28** — 올가미와 독병을 슬로우 무브먼트 스킬로 분류하고, 스킬별 배율 설정과 Brain의 공통 감속 처리로 통합.

### 001. Robe Man

| 항목 | 내용 |
| --- | --- |
| 이름 | Robe Man |

| 분류 | 일반 |
| 특징 | Hunter를 추적하며 근접 공격과 고정 지점 독병 투척을 사용하는 몬스터 |
| 구현 상태 | 동작 코드 및 프리팹 구현. 몬스터 외형·독병은 임시 표현, 독안개는 원형 위험구역으로 표시 |
| 최종 갱신일 | 2026-10-24 |

#### 행동

1. 생성 후 Hunter를 향해 이동한다.
2. 가까운 Hunter에게 근접 공격한다. 준비 동작 후 타격 순간의 거리를 확인하고 피해를 준다.
3. Hunter가 자신을 중심으로 거리 10 이내에 연속 5초 머무르면 독병 조준 조건을 달성한다. 정확히 거리 10인 위치도 포함하며, 달성 전에 범위를 벗어나면 체류 시간은 초기화된다.
4. 근접 공격 중 조건을 달성했다면 공격과 후딜이 끝나자마자 조준한다. 이미 달성한 조건은 공격 종료까지 유지한다.
5. 조준 시작 시점의 Hunter 위치를 목표 중심으로 고정한다. 이후 목표 위치는 움직이지 않으며 노란 원으로 표시한다. 조준·투척 후딜 중에는 근접 공격을 하지 않고, 공통 슬로우 무브먼트 규칙으로 감속 이동한다.
6. 조준 후 대기 시간을 두고 고정 지점을 향해 독병을 아치형으로 던진다.
7. 독병이 도착하면 병과 조준 표시가 사라지고 초록색 원형 독 위험구역이 생성된다. 이동을 막는 충돌체가 없어 통과할 수 있다.
8. Hunter가 독 범위 안에 연속 1초 머무르면 피해를 받고, 계속 머물면 1초마다 피해를 받는다. 나갔다 들어오면 노출 시간을 다시 센다.
9. 이미 던진 병과 생성된 독은 Robe Man이 죽어도 남는다. 독은 지속 시간이 끝나면 사라지고, 방 전환 및 게임 초기화 시에도 정리된다. 일시 정지·컷신 동안에는 진행이 멈춘다.

#### 현재 능력치 및 설정

### 002. Cowboy

| 항목 | 내용 |
| --- | --- |
| 이름 / 코드 식별자 | Cowboy |
| 분류 | 일반 |
| 특징 | 원거리 사격, 올가미로 Hunter 구속 또는 HauntedBull 탑승 |
| 구현 상태 | 기존 임시 외형 사용. 올가미 캐릭터 애니메이션 미구현, 머리 위에서 회전하는 작은 노란 고리로 대체 |
| 최종 갱신일 | 2026-10-28 |

#### 행동

1. 생성되면 Hunter를 향해 이동하고 사격 거리 안에서 잠시 멈춘 뒤 총을 쏜다.
2. Hunter가 사격 범위 안에 있다가 밖으로 나가면 준비 중인 사격을 취소하고 이동 속도가 느려진다. 머리 위에서 작은 노란 고리가 빙글빙글 돌며 3초간 준비한다. 이 표시는 사거리나 공격 판정이 아니며, 일시 정지 중 회전도 멈춘다.
3. 준비가 끝나는 순간 Hunter와 살아 있는 Wild HauntedBull 중 가장 가까운 대상 방향으로 올가미를 던진다. 방향은 발사 순간 고정한다. 준비·비행·회수 중에는 사격하지 않는다.
4. 올가미가 지정 거리까지 가거나 벽/장애물을 만나면 회수하고 사격 가능한 상태로 돌아온다. 사격은 Hunter가 사격 범위 안에 있을 때 실행한다.
5. Hunter에게 닿으면 사격을 재개하며 Rope로 연결하여 천천히 자신 쪽으로 끌어온다. 구속 중 일반 이동과 회피는 막고 공격은 허용한다. 끌림은 장애물을 통과하지 않는다.
6. Rope는 선을 따라 배치한 적 판정들로 구성한다. Hunter 또는 까마귀가 어느 부분이든 한 번 피해를 주면 전체 Rope가 풀린다. 별도 처치 수·처치 보상은 주지 않는다.
7. Wild HauntedBull에게 닿으면 빠르게 황소를 향해 이동한다. 도착하면 현재 체력을 황소에 저장하고 Cowboy를 숨기며 황소를 Ride로 전환한다. 접근 도중 장애물에 막히거나 대상이 사망/탑승 상태가 되면 사격 상태로 돌아간다.
8. 황소 충돌/사망으로 하차하면 탑승 시 저장한 체력으로 다시 등장하여 3초간 기절한다. 탑승은 Cowboy 처치로 계산하지 않는다.
9. Cowboy 사망/비활성화, 방 이동, 게임 초기화, Hunter 사망 또는 밧줄 최대 길이 초과 시 Rope를 정리한다.

#### 현재 설정

3초 올가미 준비와 3초 하차 기절은 요청된 값이다. 나머지는 Inspector에서 조정할 임시값이다.

| 올가미 사거리 / 속도 / 판정 반지름 | 12 / 10 / 0.55 |

## 엘리트

### 001. HauntedBull

| 항목 | 내용 |
| --- | --- |
| 이름 / 코드 식별자 | HauntedBull |
| 분류 | 엘리트 |
| 특징 | Wild/Ride 상태로 동작하는 돌진 몬스터. Cowboy 탑승 시 행동 변화 |
| 구현 상태 | 기존 돌진형 임시 외형 사용. 직사각형 공격 예고 및 Wild/Ride별 범위 설정 구현. 발 구르기 애니메이션 필요 |
| 최종 갱신일 | 2026-10-28 |

#### 행동

1. Wild 상태로 생성되어 Hunter를 추적한다.
2. Hunter가 현재 Wild/Ride 상태의 공격 시작 거리 안에 들어오면 3초간 제자리에 서서 발을 구른다. **발 구르기는 애니메이션 구현이 필요하다.** 현재 코드는 `StompStarted` 이벤트를 제공하고 황소 앞에서 Hunter 방향으로 직사각형 경고 범위를 표시한다. 표시 길이와 접촉 판정 반지름은 상태별로 설정하며 표시 폭은 해당 반지름의 2배다.
3. 발 구르기 3초 뒤 1초 더 준비하고 돌진한다. Wild는 마지막 1초 동안 방향을 고정한다. Ride는 마지막 1초에도 Hunter와 직사각형 경고 범위의 방향을 계속 맞추며, 돌진 시작 순간 방향을 고정한다. 준비 중 Cowboy가 탑승하면 즉시 Ride 범위로 전환한다. 준비 중 Inspector에서 범위 수치를 변경하면 다음 Tick에 표시 크기를 반영한다.
4. Wild에서는 벽/장애물에 닿을 때까지 돌진한다. 충돌하면 뒤로 밀려나고 3초간 행동을 멈춘다.
5. Ride에서는 지정 거리만큼 돌진하면 정상 정지한다. 발 구르기 중 탑승 Cowboy의 피해·총알 속도·발사 간격 설정으로 원거리 사격한다.
6. Ride에서 벽/장애물에 충돌하면 밀려난 뒤 Cowboy를 탑승 당시 체력으로 다시 등장시킨다. 황소는 Wild로 돌아가며 둘 다 3초간 기절한다. 기절 표시는 기존 원형을 유지하고, 황소의 다음 공격 예고는 Wild 설정의 직사각형으로 돌아간다.
7. Ride 상태로 사망하면 Cowboy를 탑승 당시 체력으로 다시 등장시키고 Cowboy만 3초 기절한다. 방 전환/초기화로 제거되는 경우에는 하차 몬스터를 생성하지 않는다.
8. Cowboy의 저장 체력은 황소 체력과 별개다. 황소가 피해를 받아도 저장된 Cowboy 체력은 줄어들지 않는다.

#### 현재 설정

발 구르기 3초, 추가 준비 1초(Wild 방향 고정 / Ride 추적 유지), 충돌/하차 기절 3초는 요청된 값이다. 나머지는 임시 조절값이다.

| 설정 | 값 |
| --- | --- |
| 최대 체력 | 120 + 방 진행 값 × 13 |
| 추적 속도 / 정지 거리 | 2.2 / 4.5 |
| Wild 공격 시작 거리 (`Wild Trigger Range`) | 6 |
| Ride 공격 시작 거리 (`Ride Trigger Range`) | 6 |
| 발 구르기 / 추가 준비 | 3초 / 1초 (Wild 고정, Ride 추적) |
| 돌진 속도 / 접촉 피해 | 12 / 22 |
| 몸 반지름 | 0.5 |
| Wild 접촉 판정 반지름 / 표시 폭 (`Wild Hit Radius`) | 1.1 / 2.2 |
| Ride 접촉 판정 반지름 / 표시 폭 (`Ride Hit Radius`) | 1.1 / 2.2 |
| Ride 정상 돌진 거리 | 8 |
| 충돌 뒤로 밀림 / 기절 | 1 / 3초 |
| 정상 돌진 종료 후 대기 | 2초 |
| Wild 직사각형 표시 길이 (`Wild Warning Length`) | 12 |
| Ride 직사각형 표시 길이 (`Ride Warning Length`) | 12 |

`Haunted Bull Attack` Inspector의 `Wild Attack Range`와 `Ride Attack Range`에서 각 상태의 공격 시작 거리, 접촉 판정 반지름, 표시 길이를 독립적으로 조절한다. 두 상태의 기본값은 기존 공통 수치와 동일하다.

직사각형은 돌진 방향을 예고하는 표시이며 영역 전체에 동시에 피해를 주지 않는다. 실제 피해는 돌진 중 황소 중심의 접촉 판정 반지름 안에 Hunter가 있을 때 적용한다. `Warning Length`는 실제 돌진 종료 거리를 바꾸지 않는다. Wild는 벽/장애물에 닿을 때까지, Ride는 `Ride Distance`만큼 돌진한다.
