# 몬스터 도감

최종 갱신일: 2026-11-09

일반 / 엘리트 / 보스 몬스터의 행동과 현재 구현 정보를 기록한다. 수치는 별도 표시가 없는 한 유니티 월드 단위와 초 단위이며, 프리팹의 저장값을 기준으로 한다. 씬 인스턴스에서 별도로 변경한 값은 다를 수 있다.

## 등록 및 갱신 규칙

- 새 몬스터를 처음 제작할 때 일반 / 엘리트 / 보스 중 어디에 넣을지 사용자에게 묻고, 정해진 분류에 등록한다. 이미 지정한 분류는 다시 묻지 않는다.
- 등록된 모든 몬스터는 수정 작업마다 도감도 최신화할지 사용자에게 묻는다. 동의한 경우에만 변경 사항과 갱신일을 반영한다. 갱신을 명시적으로 요청한 작업은 재확인하지 않는다.
- 각 항목은 이름, 분류, 행동, 능력치, 구현 상태, 관련 파일, 변경 이력을 기록한다. 임시값과 확정 조건을 구별한다.
- 작업 지침은 프로젝트 루트의 `AGENTS.md`에도 기록되어 있다.

## 공통 스킬 분류

### 슬로우 무브먼트 스킬 — 2026-10-28 추가

스킬 사용 중 일반 이동을 허용하되 이동 속도를 줄이는 공통 분류다. 각 공격 부품은 `ISlowMovementSkill`을 구현해 현재 상태의 배율을 제공하고, `EnemyBasicBrain`이 이동 부품에 전달하는 외부 속도 배율에 이를 한 번 곱한다. 사용 중이 아니면 배율 1로 복구한다.

| 스킬 | 감속 적용 구간 | Inspector 배율 | 현재 프리팹 값 |
| --- | --- | --- | --- |
| Cowboy 올가미 | 준비·비행·회수 (`Spin`, `LassoOut`, `LassoReturn`) | `Cowboy Attack → Lasso Move Multiplier` | 0.35 |
| Robe Man 독병 | 조준·투척 후딜 (`Aim`, `ThrowRecovery`) | `Robe Man Attack → Poison Move Multiplier` | 0.35 |

- 배율 범위는 0~1이다. 0은 이동 정지, 0.35는 기본 속도의 35%, 1은 감속 없음이다. Inspector 변경은 다음 일반 이동 갱신에 반영된다.
- 최종 이동 속도는 `이동 부품의 Speed × 외부 이동 배율 × 스킬 배율`이다. 이동 부품의 정지 거리·후퇴·장애물 규칙은 그대로 적용되므로 감속 구간이라고 항상 이동하는 것은 아니다.
- 공격 `Tick()`이 이동 정지를 요청하는 사격 준비·근접 공격·기절 등의 상태는 정지가 우선한다. 비활성화한 공격 부품의 스킬 배율은 적용하지 않는다.
- 독병의 고정 조준과 근접 공격 제한은 유지한다. 이미 던진 독병이나 남아 있는 독 위험구역의 수명은 시전자의 감속을 연장하지 않는다.
- Cowboy의 일반 이동은 `EnemyKeepDistanceMovement`를 사용한다. 현재 속도는 2.2, 접근 기준은 사거리 8 × 0.8 = 약 6.4, 후퇴 거리는 4이며 다른 적과의 분리 이동도 적용한다. Robe Man은 `EnemyChaseMovement`를 사용한다.
- 관련 공통 파일: `Assets/Scripts/Enemy/ISlowMovementSkill.cs`, `Assets/Scripts/Enemy/EnemyBasicBrain.cs`. 별도의 스킬 컴포넌트를 추가할 필요는 없다.

공통 변경 이력: **2026-10-28** — 올가미와 독병을 슬로우 무브먼트 스킬로 분류하고, 스킬별 배율 설정과 Brain의 공통 감속 처리로 통합.

### 001. Robe Man

| 항목 | 내용 |

| 분류 | 일반 |
| 특징 | Hunter를 추적하며 근접 공격과 고정 지점 독병 투척을 사용하는 몬스터 |
| 구현 상태 | 동작 코드 및 프리팹 구현. 몬스터 외형·독병은 임시 표현, 독안개는 원형 위험구역으로 표시 |
| 최종 갱신일 | 2026-11-03 |

#### 행동

1. 생성 후 Hunter를 향해 이동한다.
2. 가까운 Hunter에게 근접 공격한다. 준비 동작 후 타격 순간의 거리를 확인하고 피해를 준다.
3. Hunter가 자신을 중심으로 거리 10 이내에 연속 5초 머무르면 독병 조준 조건을 달성한다. 정확히 거리 10인 위치도 포함하며, 달성 전에 범위를 벗어나면 체류 시간은 초기화된다.
4. 근접 공격 중 조건을 달성했다면 공격과 후딜이 끝나자마자 조준한다. 이미 달성한 조건은 공격 종료까지 유지한다.
5. 조준 시작 시점의 Hunter 위치를 목표 중심으로 고정한다. 이후 목표 위치는 움직이지 않으며 노란 원으로 표시한다. 조준·투척 후딜 중에는 근접 공격을 하지 않고, 공통 슬로우 무브먼트 규칙으로 감속 이동한다.
6. 조준 후 대기 시간을 두고 고정 지점을 향해 독병을 아치형으로 던진다.
7. 독병이 도착하면 병과 조준 표시가 사라지고 초록색 원형 독 위험구역이 생성된다. 이동을 막는 충돌체가 없어 통과할 수 있다.
8. Hunter와 RobeMan을 제외한 적이 독 범위 안에 연속 1초 머무르면 각각 5의 피해를 받고, 계속 머물면 1초마다 반복된다. 모든 RobeMan은 면역이다. 대상별로 노출 시간을 따로 계산하며 나갔다 들어오면 다시 센다.
9. 이미 던진 병과 생성된 독은 Robe Man이 죽어도 남는다. 독은 지속 시간이 끝나면 사라지고, 방 전환 및 게임 초기화 시에도 정리된다. 일시 정지·컷신 동안에는 진행이 멈춘다.

### 002. Cowboy

| 항목 | 내용 |
| --- | --- |
| 이름 / 코드 식별자 | Cowboy |
| 분류 | 일반 |
| 특징 | 원거리 사격, 올가미로 Hunter 구속 |
| 구현 상태 | 기존 임시 외형 사용. 올가미 캐릭터 애니메이션 미구현, 머리 위에서 회전하는 작은 노란 고리로 대체 |
| 최종 갱신일 | 2026-10-28 |

#### 행동

1. 사격 거리 8 이내에서 0.6초간 멈춰 준비한 뒤, 준비 시작 때 기록한 Hunter의 몸 중심 위치를 향해 탄환 3발을 부채꼴로 쏜다. 탄환 사이 각도는 16도이며 기본 피해는 발당 13이다. 탄환 수·피해·속도·수명·간격각은 Inspector에서 조절하며 발사 시점의 값을 사용한다.
2. Hunter가 사격 범위 안에 있다가 밖으로 나가면 준비 중인 사격을 취소하고 이동 속도가 느려진다. 머리 위에서 작은 노란 고리가 빙글빙글 돌며 3초간 준비한다. 이 표시는 사거리나 공격 판정이 아니며, 일시 정지 중 회전도 멈춘다.
3. 준비가 끝나는 순간 Hunter 방향으로 올가미를 던진다. 방향은 발사 순간 고정한다. 준비·비행·회수 중에는 사격하지 않는다.
4. 올가미가 지정 거리까지 가거나 벽/장애물을 만나면 회수하고 사격 가능한 상태로 돌아온다. 사격은 Hunter가 사격 범위 안에 있을 때 실행한다.
5. Hunter에게 닿으면 사격을 재개하며 Rope로 연결하여 천천히 자신 쪽으로 끌어온다. 구속 중 일반 이동과 회피는 막고 공격은 허용한다. 끌림은 장애물을 통과하지 않는다.
6. Rope는 선을 따라 배치한 적 판정들로 구성한다. Hunter 또는 까마귀가 어느 부분이든 한 번 피해를 주면 전체 Rope가 풀린다. 별도 처치 수·처치 보상은 주지 않는다.
7. Cowboy 사망/비활성화, 방 이동, 게임 초기화, Hunter 사망 또는 밧줄 최대 길이 초과 시 Rope를 정리한다.
8. 일반 이동이 허용되는 동안에는 Hunter와의 거리가 약 6.4를 초과하면 접근하고 4 미만이면 후퇴한다. 그 사이에서는 목표 방향 이동을 멈추지만 다른 적과의 분리 이동은 적용한다. 사격 준비·발사 프레임에는 이동을 멈추고, 올가미 준비·비행·회수 중에는 이 거리 유지 이동에 감속 배율을 적용한다.

#### 현재 설정

3초 올가미 준비는 요청된 값이다. 나머지는 Inspector에서 조정할 임시값이다.

| 설정 | 값 |
| --- | --- |
| 최대 체력 | 65 + 방 진행 값 × 13 |
| 이동 속도 / 접근 기준 / 후퇴 거리 | 2.2 / 사거리 8 × 0.8 = 약 6.4 / 4 |
| 공격 사거리 연동 / 수동 기준 거리 / 접근 비율 | ON / 8 (연동 OFF 시 사용) / 0.8 |
| 몸 반지름 / 적 간 분리 거리 제곱 / 분리 강도 | 0.5 / 1.4 / 0.7 |
| 사격 거리 / 준비 / 재사용 대기 | 8 / 0.6초 / 1.5초 |
| 총알 피해 / 속도 / 수명 | 13 / 7 / 4초 |
| 탄환 수 / 탄환 사이 각도 | 3발 / 16도 (중앙 기준 -16도·0도·+16도) |
| 사격 예고 반지름 / 최초 사격 대기 범위 | 0.8 / 0~0초 |
| 올가미 준비 | 3초 |
| 준비 고리 높이 / 공전 반지름 / 지름 / 초당 회전 | 1.8 / 0.35 / 0.45 / 2회 (임시 연출값) |
| 올가미 사거리 / 속도 / 판정 반지름 | 12 / 10 / 0.55 |
| 올가미 중 이동 배율 | 0.35 (기본 속도의 35%) |
| Hunter 끌어오는 속도 | 1.2 |
| 밧줄 최대 길이 | 올가미 사거리 × 1.5 = 18 |

#### 행동

1. 풀 차지를 바로 사용할 수 있는 추적 상태로 생성되어 Hunter를 향해 이동한다.
2. 풀 차지를 사용할 수 있고 Hunter가 공격 시작 거리 6 이내에 들어오면 3초간 제자리에 서서 발을 구르며 Hunter 방향을 추적한다. **발 구르기는 애니메이션 구현이 필요하다.** 현재 코드는 `StompStarted` 이벤트를 제공하고 황소 앞에서 Hunter 방향으로 직사각형 경고 범위를 표시한다. 표시 길이와 접촉 판정 반지름은 설정하며 표시 폭은 해당 반지름의 2배다.
3. 발 구르기 3초 뒤 1초 더 준비하고 돌진한다. 마지막 1초 동안 방향을 고정한다. 준비 중 Inspector에서 범위 수치를 변경하면 다음 Tick에 표시 크기를 반영한다.
4. 풀 차지는 벽/장애물에 닿을 때까지 돌진한다. 충돌하면 뒤로 밀려나고 3초간 행동을 멈춘다. 풀 차지 종료부터 10초 쿨타임을 시작하며 기절 중에는 풀 차지·숏 차지의 쿨타임이 모두 정지한다.
5. 풀 차지 쿨타임 중에는 Hunter에게 접근하여 거리 2.5 이내에서 숏 차지를 사용한다. 0.2초 조준 후 0.1초 방향을 고정하고, 속도 10으로 거리 3만큼 돌진한 뒤 멈춘다. 숏 차지 종료 후 재사용 대기는 1.5초다. 벽·장애물에 먼저 닿으면 풀 차지와 동일하게 뒤로 밀리고 3초 기절한다.
6. 숏 차지 명중 시 헌터를 진행 방향으로 거리 3만큼 0.3초 동안 밀어낸다. 외형은 최대 높이 0.45의 아치형으로 떠올랐다 착지하고 그림자는 지면에 유지된다. 이동 경로의 장애물 판정은 유지한다. 풀 차지 명중 시 헌터는 조작이 제한된 채 황소와 함께 이동하며, 황소나 헌터가 먼저 벽·장애물에 닿으면 놓아주고 헌터를 1초 기절시킨다. 황소 사망·비활성화·공격 취소 시에는 추가 기절 없이 해제한다. 돌진당 명중 효과는 한 번이며 회피·피격 무적 중에는 피해와 제어 효과를 적용하지 않는다.

- 체력 350, 방당 체력 증가 0. 생존 중 체력 150 이하에서 5초 확대 컷신 후 2페이즈로 전환한다. Space/Esc 또는 버튼으로 스킵할 수 있다.
- 1페이즈 우선순위는 총 난사 → 기관총 평타. 기관총 조준 중 총 난사 조건이 충족되면 평타를 취소하고 스킬로 전환한다. 발사 중인 기관총은 발사와 후딜을 마친 뒤 다음 패턴을 선택한다. 조준 중에는 거리 유지 이동하고, 실제 발사 중에는 정지한다. 총 난사 도약 중에는 도약 동작만 수행한다.

- 총 난사는 근접 시 장애물을 피해서 뒤로 도약한 뒤 조준한다. 두 총격은 조준 종료 지점을 고정하며 총 난사는 좌우 왕복한다.
- 2페이즈 우선순위는 채찍 → 다이너마이트 → 샷건. 샷건 휘두르기·조준 중 스킬이 준비되면 평타를 취소하고 전환한다. 발사 후에는 후딜을 마쳐야 다음 패턴을 선택한다. 샷건 시작 시 근접하면 총을 휘둘러 넉백·0.5초 기절을 주고 조준한다.

Logan은 스킬 실행 중 및 모든 패턴의 후딜 중 다른 패턴으로 전환하지 않는다. 예외적으로 발사 전 평타는 준비된 스킬로 전환할 때 취소한다. 발사 중인 기관총과 후딜 중에는 외부 Signal 메서드도 거절된다. 투척한 다이너마이트의 비행·도화선 및 이미 발사된 탄환은 독립적으로 진행되므로 투척/사격 동작 종료 후 다음 패턴과 함께 남아 있을 수 있다. 사망·비활성화·사용 토글 해제·체력에 따른 페이즈 전환 컷신은 공격 패턴 교체와 별개의 취소 사유다.

### 패턴별 후딜레이

기관총 평타·총 난사·샷건 평타·채찍·다이너마이트 모두 현재 프리팹의 Recovery Seconds는 0.5초다. 조절 가능한 임시값이며 0이면 후딜이 없다. Unity에서 Logan 프리팹 루트 → Logan Boss Attack → 각 패턴 설정 → Recovery Seconds로 변경한다.

발사/채찍 공격/투척 동작이 끝나면 Recovery 상태로 들어가며 이동과 다음 공격을 막는다. 도약 후 조준, 샷건 휘두르기 후 조준은 같은 패턴 내부 단계이므로 그 사이에는 별도 후딜을 넣지 않는다. 다이너마이트 후딜은 투척 동작 직후 시작하며 이미 던진 폭탄의 비행·폭발은 독립적으로 진행한다. 공격 쿨타임은 공격 동작 종료부터 시작해 후딜 중에도 감소하고 후딜 종료 시 재설정하지 않는다. 평타의 발사 전 스킬 전환, 사망·비활성화·페이즈 전환 등 취소는 후딜을 기다리지 않는다. 채찍 가속 및 접근 거리 변경은 후딜 시작 시 복원한다.

### 다이너마이트 회피 도약

Logan은 아직 폭발하지 않은 다이너마이트의 착지 예정 범위와 착지 후 폭발 범위를 감지한다. 자신의 몸 반지름과 안전 여유를 포함한 범위 안이면, 겹친 모든 다이너마이트 범위 밖이면서 벽·장애물을 통과하지 않는 위치로 아치형 도약한다. 다른 Logan이 던진 다이너마이트도 같은 방식으로 감지한다.

도약 거리 이내에서 5도 방향·최대 0.1 거리 간격으로 후보를 검사하고, 안전 후보 중 헌터에게서 가장 먼 지점을 택한다. 안전한 착지점이 없으면 도약하지 않는다. 회피 자체에 무적은 없으며 폭발 전에 범위를 벗어나지 못하면 피해를 받을 수 있다.

회피 중에는 기존 공격/후딜 및 쿨타임을 잠시 멈추고 새 공격 신호를 받지 않는다. 착지 후 기존 상태를 이어간다. 총 난사 도약 도중 회피했다면 회피 착지를 기존 도약의 완료로 처리하고 조준부터 진행한다. 이동 경로에 장애물이 생기면 진행을 멈추며 다음 갱신에서 다시 위험 여부를 판단한다. 사망·비활성화·페이즈 전환 시에는 도약 높이를 복원하고 회피를 취소한다.

| Logan Boss Attack 설정 | 현재 프리팹 값 |
| --- | --- |
| Enable Dynamite Dodge | ON |
| Dodge Distance | 4 |
| Dodge Seconds | 0.4초 |
| Dodge Height | 0.7 |
| Dodge Safety Margin | 0.2 |

위 수치는 조절 가능한 임시값이다. Unity에서 Logan 프리팹 루트 → Logan Boss Attack → Dynamite avoidance에서 조절한다. 별도 컴포넌트 연결은 필요 없다. 전용 코드는 `Assets/Scripts/Enemy/Enemy_Boss_Logan/LoganDynamiteDodge.cs`이며 `LoganDynamiteVolley.Threatens`가 위험 영역을 제공한다. Logan 내부 전용 기능으로 관리한다.
