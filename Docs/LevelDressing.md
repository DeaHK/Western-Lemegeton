# 황야 여섯 방 환경 정리

제공된 신데리아 화면에서 참고한 것은 가장자리의 밀도, 통로로 이어지는 지면, 플레이어와 문/소품의 상대 크기입니다. 기존 서부 황야 PNG를 재배치하며 캐릭터 크기와 카메라 시점은 유지합니다.

## 크기 기준

사냥꾼의 서 있는 높이 1.9를 기준으로 문 전체 높이 5.2, 마차 3.5–3.9, 수레 1.8–2.25, 선인장 2.4–3.5, 통/상자 0.9–1.2, 울타리 1.25–1.7을 사용합니다. 원본 종횡비는 유지합니다. 플레이 구역의 소품은 같은 종류의 크기 범위를 통일하며, 절벽·전경 바위는 지형 덩어리이므로 크기를 다양하게 유지합니다. 히르바 건물의 기존 도로 간격은 유지합니다.

`WesternEnvironment.PropWidth`에서 최종 폭을 계산하고 실제 소품과 충돌 영역이 같은 값을 사용합니다. 문은 기둥·간판을 포함한 전체 그림 높이로 측정하며 개구부 높이와 혼동하지 않습니다.

## 배치

- 여섯 방의 실제 문 위치를 확인한 후 가장자리 바위 군락을 배치합니다. 방 입구와 문 접근 구간은 비워 둡니다.
- 문 양쪽에 바위, 부서진 울타리, 마른 풀을 묶어 경계와 통로를 만듭니다.
- 중앙에서 각 문으로 옅은 흙길을 이어 주고, 짧게 끊어진 바퀴 자국과 길 가장자리 자갈을 넣습니다.
- 전투 중앙은 넓게 두고 작은 장식은 엄폐물 주변으로 모읍니다. 바위 밑의 흙과 기존 접지 그림자를 유지합니다.
- 성흔 방은 예배당 배치를 사용해 보상 공간의 성격을 구분합니다.
- 길과 장식의 배치는 결정적이며 전투 난수나 보상에는 영향을 주지 않습니다.

`FrontierDressing.cs`가 문 위치에 따른 군락과 길을 담당합니다. `ExplorationStage.cs`가 실제 연결문을 만든 후 이를 호출합니다. 문 색상은 기존 전투 잠금/해제 상태를 따릅니다.

여섯 방 탐험·보상 완료 후 마지막 문에서 E를 눌러 로그 맵을 여는 규칙은 유지합니다.

## 검증

빌드 시 여섯 방의 연결문·보상 지점까지 접근 가능한지 검사합니다. `--level-test`는 여유 반경 0.65의 경로를 찾아 실제 플레이어 충돌 처리로 각 경유점까지 이동한 후 여섯 방과 모든 문 주변을 캡처합니다. 완료 후 마지막 문 상호작용으로 로그 맵이 열리는지도 확인합니다. `--smoke-test`는 30방·50웨이브와 기존 전투·Timeline 검증입니다.

최종 결과(2026-09-15): Windows 빌드 성공, 레벨 접근/이동 494개 검사와 기존 통합 4254개 검사 통과, 30방·50웨이브 완료. 문 앞 바위 가림, 북쪽 문과 예배당 겹침, 개구부에 선 플레이어 때문에 문 전체가 흐려지는 현상을 실제 게임 화면에서 보정했습니다. 대표 화면은 Previews/LevelPassage.png, Previews/LevelWilderness.png, Previews/LevelSigilRoom.png에 저장했습니다.
