# 성흔 시스템 — 현재 구현과 사용자 확인 목록

작업 종료 시점의 통합 인수인계는 [2026-10-17 성흔 작업 통합 정리](STIGMA_WORK_SUMMARY_2026-10-17.md)에 있다. 이 문서는 세부 구현과 확인 목록이다.

작성: 2026-10-17. 현재 범위는 **성흔방 혼합 카드 3택1 + 보유 성흔 교체·강화 + 실제 전투 효과 + G 연계스킬 6종과 대가**다. 플레이어 일반 스킬에도 흔적 부여를 연결했다. 아래 구현 내용은 코드·저장 데이터 기준이며, Unity Play 동작은 사용자가 확인한다.

사용자 후속 확인: 기본 플레이와 혼합 카드 흐름이 잘 동작한다고 보고했고, 최종적으로 이번 범위 종료와 문서 정리를 요청했다. 후속 화면에서 플라그라 새 아이콘 표시도 확인했다. 교체 무료·G 범위 확대·플라그라·독립 레벨 저장 등은 구현했으나 모든 세부 수치가 개별 플레이 검증되었다는 보고는 없다. 아래 목록은 재확인용이다.

## 실제 이용 방법

1. Main에서 Play → 마을 → 던전으로 진입한다. 첫 층의 성흔방 중앙 제단에서 **F**를 누른다.
2. **플레이어용·까마귀용을 섞은 최대 3장**이 나온다. 카드를 눌러 상세 효과를 보고 **플레이어용/까마귀용 카드 획득** 버튼으로 1장을 무료 확정한다. 방 전체에서 총 1장이다.
3. 확정한 성흔만 카드에 적힌 대상의 원형 6칸에 추가된다. 해당 대상의 첫 성흔은 자동 장착하고, 이미 장착 중이면 다른 계열의 새 성흔은 보관한다. 현재 장착한 하위 성흔의 강화를 획득한 경우 새 강화 성흔 Lv.1로 자동 교체한다. 후보를 구경하는 동안에는 획득 칸이 늘지 않는다.
4. 상단 **플레이어 / 까마귀** 또는 **보유 성흔 관리** 버튼으로 관리 화면에 들어간다. 보유 성흔끼리 무료 교체할 수 있다. **강화** 버튼은 선택 후보가 아니라 해당 대상의 현재 장착 성흔을 강화하며 동전이 필요하다. 미획득 후보를 교체 버튼으로 얻을 수는 없다.
5. ESC/돌아가기로 닫고 제단을 다시 F로 열 수 있다. 닫기·재방문·대상 전환으로 후보가 바뀌거나 획득 기회가 추가되지 않는다. 획득 후에도 교체·강화는 가능하다. 거래 없이 닫아도 방은 완료 처리되지만 미사용 획득 기회는 해당 방에 남는다.
6. 전투에서 **플레이어 기본 공격 또는 일반 스킬**과 **까마귀 Command 일반 공격**으로 같은 적에게 흔적 한 쌍을 붙여 표식을 모은 뒤 **G**로 현재 조합 스킬을 사용한다. F의 기존 기능은 유지한다.

적 처치 시 일반 적 50 / 보스 500 동전을 지급한다(임시값). F9의 **동전 +2000**, **표식 최대**로 테스트 준비를 줄일 수 있다. HUD에서 표식·동전·가상체력을 확인한다. 일반 HUD로 연 관리 화면은 조회용이며 제단 밖 교체·강화는 잠긴다.

## 장착·거래·자원 규칙

- 플레이어/까마귀의 획득 목록, 장착 성흔, 단계는 독립이다. 같은 종류도 각각 획득해야 한다. 한쪽만 장착하면 고유 효과·조합 보너스·연계스킬은 비활성이다.
- 성흔방 후보는 InitialChoice 정의의 **소유자+성흔 ID** 쌍에서 해당 소유자가 이미 가진 항목을 제외하고 무작위 최대 3장을 제시한다. 강화 성흔은 같은 대상이 BaseDefinition을 보유해야 후보 풀에 추가되며 출현을 보장하지 않는다. 강화 성흔을 보유하면 하위 성흔의 재획득·장착을 막는다. 같은 종류라도 반대 대상의 보유 상태는 독립이다. 두 소유자가 반드시 모두 나오는 보장은 없다. 남은 후보가 1~2장이면 그 수만 표시하고, 0장이면 관리 화면만 이용한다.
- 방의 최초 후보와 총 1장 획득 여부는 런의 층·방별로 기억한다. 다음 층의 새 성흔방에는 새 획득 기회가 있다. 새 런/성흔 디버그 초기화 시 기록을 비운다. 방 밖 획득용 TryAcquire와 방 카드 ClaimCard는 별도 API다.
- 레벨은 **대상 + 성흔 ID별**로 저장한다. 신규 획득은 강화 성흔을 포함해 Lv.1이다. 예: 플레이어 플라그라 Lv.3, 플레이어 로스 Lv.2, 까마귀 로스 Lv.1이 독립이다. 교체 시 장착 슬롯의 레벨을 전달하지 않고 선택 성흔의 저장 레벨을 복원한다. 강화는 현재 장착 성흔만 1→2→3으로 올린다.
- 둘 다 장착했을 때 기본 성흔 고유 효과와 조합/G는 **현재 장착한 양쪽 성흔 중 낮은 단계**를 사용한다. 플라그라는 UseOwnerLevel=true로 플레이어가 보유한 플라그라 자신의 레벨을 고유 효과에 적용한다. 미장착 성흔 설명·장착 시 조합·슬롯 레벨도 해당 성흔의 저장 레벨을 읽는다. 미장착 성흔 선택 시 강화 버튼은 ‘선택 성흔 장착 후 강화’로 안내한다.
- 교체는 모든 단계에서 무료다(사용자 요청으로 원본 기획 변경). 강화 비용은 기존 400/1000 동전을 유지한다. 강화 잔액 부족·최대 단계·동일 성흔 재장착은 거래하지 않는다.
- 원형 슬롯은 페이지당 6칸. 처음은 비어 있고 획득할 때 채워진다. 7종 이상은 페이지를 나눈다. 강화 성흔은 별도 정의·획득 항목이다. 하위를 장착한 상태에서 강화를 획득하면 새 강화 성흔 Lv.1로 즉시 교체한다. 하위 레벨은 별도 기록으로 남고 전달되지 않는다. 다른 계열을 장착 중이면 보유 목록에 추가한다. 하위 항목은 목록에 남고 장착 불가를 표시한다. InitialChoice가 아닌 정의는 외부 획득 API로 얻은 뒤 교체 후보에 나타난다.
- 플레이어 검·총 기본 공격, 검 스킬 Slash/Slam 및 총 스킬 Shot/Barrage와 까마귀 Command 일반 공격은 출처별 흔적을 남긴다. 까마귀 콤보 후속타, 기존 까마귀 연계, G 스킬, 사역마, 지속 피해는 흔적을 남기지 않는다. 일반 스킬의 다단/범위 타격도 적별 최대 1회 표식 전환 규칙을 따른다.
- 적의 금색/청록 반원이 각각 플레이어/까마귀 흔적이다. 두 흔적을 표식 1개로 전환한다. 현재 적당 최대 1회이며, `MaxChargeGrantsPerEnemy=0`으로 향후 반복 허용을 전환할 수 있다. 마지막 타격에서도 전환을 먼저 처리한다.
- 표식 상한은 조합 비용×2. 방·층 이동 시 유지, 사망·새 런 시 초기화한다. 교체 시 새 상한까지만 제한하며 부족분을 채우지 않는다. 상한에 도달한 동안에는 추가 표식을 얻지 않고 적의 흔적은 남는다.
- 교체·단계 변경 시 이전 성흔의 버프·디버프·가상체력·흔적·사역마·장판을 정리한다. 다른 출처의 공통 스탯 modifier와 가상체력 기여분은 별도로 보존한다. 이동 시 사역마·장판은 정리한다.
- 가상체력은 기본 체력과 별도다. 등록된 효과/패시브 중 가장 큰 부여량을 상한으로 삼고 초과 누적하지 않는다. 적 피해는 가상체력부터 소모한다.
- 공속·공격력 버프는 합산, 같은 처치 버프는 지속시간 갱신. 감속은 최대 -50%. 감속 대상 받는 피해 +10%는 한 번만 적용한다.
- 처치 보상은 실제 공격 주체를 따른다. 사역마와 현재 G 화염 장판은 플레이어 소유다.

## 임시 강화 성흔 — 플라그라

사용자가 요청한 임시 콘텐츠. 이름은 플라그라, ID는 `flagra`다. **플레이어 전용**이며 까마귀의 카드·디버그 목록에서 제외하고 획득·장착 API에서도 차단한다. 아르도르의 처치 공속·상시 이속을 위 강화 수치로 대체하며 원본 효과를 중복 합산하지 않는다. 처치 공속은 재처치 시 지속시간 갱신이다. `UseBaseCombination=true`로 명시하여 아르도르의 조합을 계승한다. 플라그라+로스=증발, +우무스=화재, +아르도르=업화다.

공통 추가 효과 **잔탄 연소**는 플레이어 원 샷의 사거리를 4→8로 늘리고, 발사 직전 잔탄에 따라 기본 원 샷 피해에 아래 배율을 곱한다. 플레이어 플라그라의 공속·이속·원 샷 피해·재장전 혜택은 **플레이어 자신의 장착 레벨**을 적용한다. 예: 플레이어 Lv.3/까마귀 Lv.1이면 고유 효과 Lv.3, 조합/G Lv.1이다. 기존 양쪽 장착 활성화 조건은 유지한다.

|---|---:|---:|---:|
| 0 | 1.1 | 1.1 | 1.1 |
| 1 | 1.5 | 1.6 | 1.7 |

- 발사하면 잔탄을 모두 소모하고 새 재장전을 시작한다. 기존 일반 재장전의 남은 시간은 이어받지 않는다. 빗맞힘/0발에도 동작하며 발사 전 취소는 소모하지 않는다.
- 플라그라 원 샷 쿨타임은 발사 직전 잔탄으로 스냅샷한다. 0발 70% 감소→6발 0% 감소를 선형 보간: 0~6발 순서로 70 / 58.33 / 46.67 / 35 / 23.33 / 11.67 / 0%. 기본 8초 기준 2.4 / 3.33 / 4.27 / 5.2 / 6.13 / 7.07 / 8초다. 내부 계산은 반올림하지 않는다. 기존처럼 스킬 종료·취소부터 쿨타임이 시작되며 발사 전 취소에는 기본 쿨타임을 적용한다. 다른 스킬·일반 원 샷에는 이 쿨감을 적용하지 않는다.
- `Hunter.prefab > Player > Base Reload Seconds`가 공통 기본 재장전 시간이며 기본값은 기존과 같은 2초다. `Reload`는 기본 시간 기준 남은 작업량, HUD와 F9의 남은 시간은 현재 속도로 환산한 값이다.
- 일반 재장전은 공속과 무관하다. 강화 원 샷에서 시작한 재장전만 `현재 플레이어 공속 배율`만큼 진행한다(최소 0.1). 재장전 중 처치 버프 발동·갱신·만료도 실시간 반영한다.
- Lv.3은 이 재장전 완료 시 회피 쿨타임을 0으로 만든다. 일반 재장전에는 적용하지 않는다. 성흔 교체/단계 변경/초기화로 효과 출처가 바뀌면 진행 중 재장전은 일반 속도로 계속하고 회피 초기화 혜택은 제거한다. 무기 교체는 기존처럼 재장전을 유지한다.
- 애니메이션 및 배속 연결은 변경하지 않았다. 재장전 처리와 원 샷 효과 모듈을 분리해 이후 연결할 수 있다.
- 새 아이콘 `Assets/Resources/Stigmas/Icons/FlagraIcon.png`를 Sprite로 등록하고 정의의 Icon에 연결했다. 이미지 생성 도구로 제작했으며 원본 RGBA/투명도를 보존했다. 생성 프롬프트는 [FLAGRA_ICON_PROMPT.txt](FLAGRA_ICON_PROMPT.txt)에 저장했다. 최초 Combat 폴더 배치는 WesternArtImporter가 Texture로 강제 변경해 대체 불꽃이 표시되는 문제가 있었다. GUID를 유지해 전용 Icons 폴더로 옮기고 해당 폴더를 Sprite/Single로 가져오도록 임포터를 수정했다. 다른 Combat/Western 이미지의 기존 임포트 방식은 유지한다.

### 플라그라 사용자 확인

1. 새 런/성흔 초기화 상태의 성흔방에는 강화 카드가 없어야 한다. 플레이어만 아르도르를 보유하면 다음 새 성흔방 후보 풀에 플레이어용 플라그라만 추가된다. 무작위이므로 매번 나오지는 않는다. 이미 열린 방의 후보는 그대로 유지한다.
2. 아르도르를 장착한 대상이 플라그라 카드를 획득하면 새 플라그라 Lv.1로 자동 교체. 하위 아르도르를 다시 장착할 수 없어야 한다. 반대 대상의 아르도르 장착은 가능하다.
3. F9 플레이어에서 하위 없이 플라그라 선택 → **즉시 지급·장착**. 까마귀는 아르도르 Lv.1로 두고 플레이어만 Lv.1/2/3으로 바꾼다. 플라그라 새 아이콘·공속·이속·원 샷 효과는 플레이어 단계, 조합/G는 Lv.1인지 확인한다. 까마귀 탭에는 플라그라가 없어야 한다.
4. 현재 실제 입력은 Q 무기 교체, E 첫 스킬(리볼버 원 샷), R 두 번째 스킬이다. F9의 탄 0~6 버튼으로 잔탄을 고정한 뒤 원 샷을 사용한다. F9에 표시된 배율/사거리/쿨감과 타격 범위·잔탄 0·새 재장전을 확인한다. 같은 관통 사격에 맞은 적은 모두 발사 시 잔탄 배율을 사용해야 한다. 0발 쿨타임 2.4초, 3발 5.2초, 6발 8초를 확인한다(종료 이후 경과 시간만큼 HUD에서 감소함).
5. 원 샷으로 적을 처치해 공속 버프가 생기면 그 재장전이 빨라져야 한다. 일반 재장전에는 공속이 적용되지 않아야 한다. 기본 2초, 공속 1.4배 유지 시 약 1.43초다(다른 공속 보너스는 합산).
6. Lv.3에서 회피를 쓴 뒤 강화 원 샷 → 재장전 완료 시 회피 쿨타임 0. Lv.1/2와 일반 재장전에는 초기화 없음. 진행 중 F9로 성흔 교체 → 기존 혜택 제거를 확인한다.
7. 애니메이션 타이밍 변화 없이 이동·기본 공격·다른 스킬·무기 교체·새 런이 정상인지 확인한다. Play/자동 런타임 검증은 실행하지 않았다.

## G 연계스킬 확인표

순서는 플레이어+까마귀 어느 쪽이어도 같다. 아래 단계는 낮은 쪽 장착 단계다.

| 조합 / 비용·상한 | Lv.1 기준 동작 | 강화 및 대가 확인 |
|---|---|---|
| 로스+로스: 범람 / 2·4 | 주변 적 감속 40%, 4초 | Lv.2 범위·시간 증가, Lv.3 범위 증가와 받는 피해 +10%. 별도 대가 없음 |
| 우무스+우무스: 개화 / 2·4 | 가상체력 15, 가상체력 중 공격력 +10% | Lv.2 가상체력 20, Lv.3 처치 시 재충전. 중복 사용으로 상한 초과하지 않음 |
| 아르도르+아르도르: 연소 질주 / 3·6 | 양쪽 공속 +30%, 3초 | 종료 후 플레이어 1.5초 감속 15%. Lv.2 4초, Lv.3 임시 5초·대가 1초. 재사용은 갱신 |

사용자 요청으로 확대한 현재 반경(Lv.1/2/3): 범람 6/7/8, 늪 폭발 4/5/6, 대폭발·장판 5/6/7. 사역마 탐색 거리 14·소멸 폭발 반경 3, 대폭발 지정 사거리 14, 늪 폭발 중심의 전방 거리 4다. 기존 반경의 2배이므로 원형 적용 면적은 4배다. 판정과 범위 연출은 같은 데이터를 사용한다. 개화·연소 질주는 대상에게 직접 적용하는 버프여서 범위 판정이 없다.

## 사용자 테스트 순서

### 1. 성흔방과 대상 분리

- 초기에는 양쪽 6칸이 모두 비었는지 확인한다.
- 제단에 최대 3장의 카드가 나오고 각 카드에 플레이어용/까마귀용이 명시되는지 확인한다. 획득하지 않고 ESC → F, 대상 탭 → 카드 선택으로 돌아가도 후보가 같아야 한다.
- 카드 한 장 획득 → 해당 대상만 1칸 추가·첫 성흔 자동 장착. 같은 방에서는 반대 대상 카드도 추가 획득할 수 없어야 한다. 닫기·재방문 후에도 동일하다.
- 다음 층 성흔방에서 이미 가진 소유자+성흔 조합은 후보에서 빠져야 한다. 반대 대상도 허용되는 성흔은 해당 대상의 별도 후보가 될 수 있다. 현재 장착 성흔의 강화형이 아닌 새 카드는 보유 목록만 늘고 장착은 유지되어야 한다.
- 다른 대상 카드도 획득하거나 F9로 지급하여 양쪽 장착 → 중앙에 조합이 표시되는지 확인한다. 한쪽만 장착하면 효과는 비활성이다.
- 기본 성흔 조합에서 한쪽만 Lv.3 강화 → 다른 쪽 Lv.1이면 고유/조합 효과 Lv.1인지 확인한다. 플라그라는 고유 효과만 자기 레벨을 따르는 예외이며 조합/G는 그대로 Lv.1이다.
- 플레이어 플라그라 Lv.3에서 신규 로스 선택 → 로스 Lv.1 미리보기, ‘선택 성흔 장착 후 강화’가 표시되어야 한다. 로스 장착 후 Lv.2로 강화 → 플라그라로 복귀하면 Lv.3, 다시 로스로 복귀하면 Lv.2여야 한다. 까마귀 로스 Lv.1은 그대로여야 한다. 무료 교체 시 동전·획득 목록 변화 없음도 확인한다.
- 동전 부족, 최대 단계, 동일 성흔 재확정으로 중복 차감이 없는지 확인한다.
- ESC 후 제단 F로 재진입 가능, 제단 밖 관리 UI에서는 거래가 불가능한지 확인한다.

### 2. 흔적과 표식

- F9에서 양쪽 성흔을 지급→장착하고 표식을 0으로 설정한 뒤 닫는다.
- 같은 적에게 플레이어 기본 공격만 반복 → 한쪽 반원만 남고 표식은 증가하지 않아야 한다.
- 새 적에게 기본 공격 없이 검·총의 E/R 스킬 각각 사용 → 플레이어 흔적이 남아야 한다. 이어서 까마귀 Command 공격으로 표식 1개가 생기는지, 역순으로도 생기는지 확인한다. 범위 스킬은 맞은 적마다, 다단 스킬은 적별 최대 1회 전환이어야 한다.
- 까마귀 Command 일반 공격을 맞히면 표식 1 증가·반원 소모. 같은 적으로 다시 표식을 얻지 않아야 한다.
- 콤보 후속타와 G 공격만으로 반원이나 추가 표식이 생기지 않아야 한다.
- 마지막 일격으로 두 번째 흔적을 완성해도 표식을 받아야 한다. 방·층 이동은 표식 유지, 사망은 0이다.

### 3. 고유 효과와 G 6종

- F9에서 각 조합을 장착하고 양쪽 Lv.1 → **표식 최대** → F9 닫기 → G 순으로 위 표를 확인한다. 같은 순서로 Lv.2/3도 확인한다.
- F9 공속 배율은 P/R이 따로 표시된다. 아르도르를 낀 대상이 처치했을 때 해당 공속이 오르고, 시간 경과로 돌아오는지 확인한다.
- 우무스 처치와 개화로 가상체력이 표시되고, 반복 획득해도 상한을 넘지 않는지 확인한다. 피격 시 가상체력이 먼저 감소해야 한다.
- 범람/로스 Lv.3 피해 증가가 +20%로 중첩되지 않는지, 이동 감속이 -50%를 넘지 않는지 확인한다.
- 연소 질주 종료 뒤 대가 발생·해제, 사역마 존재 중 감속·소멸 후 해제를 확인한다.
- 사역마 처치가 플레이어 킬·동전·플레이어 소유 처치 효과로 이어지는지 확인한다.
- 대폭발로 가상체력이 줄지 않고 기본 체력만 소모되는지 확인한다. 체력 부족 시 표식도 남아야 한다.

### 4. 교체와 유지

- 진흙 표식 8에서 로스+로스로 변경 → 4로 제한. 표식 2에서 같은 변경 → 2 유지.
- 성흔 버프·가상체력이 있을 때 성흔방에서 교체 → 성흔 출처 효과 제거. 일반 패시브 스탯은 유지.
- F9 교체 우회로 사역마/장판을 남긴 상태를 만들고 교체 → 이전 오브젝트와 감속 대가가 제거되어야 한다.
- 새 런 → 양쪽 목록·단계·표식·동전·가상체력 초기화.
- UI 한글/아이콘 누락, 설명 잘림, 버튼 겹침도 확인한다. 실패 시 조합, 양쪽 단계, 직전 조작과 실제 증상을 함께 남긴다.

## 코드 책임과 확장 위치

- `Core/StigmaLoadout`: 대상별 획득·장착·단계·조합 상태만 소유.
- `Core/StigmaManager`: Unity 수명, 상태 변경 전달, G 입력 연결.
- `Core/StigmaRoomService`: 룸 제한, 소유자 혼합 카드 후보·방별 획득 기록, ClaimCard, 보유 성흔 교체·강화 가격 검증과 Purchase.
- `Core/StigmaResources`: 런 동전, 출처별 가상체력, 적이 소유하는 흔적·디버프 상태.
- `Core/StigmaCombat`: 효과 실행, 공통 스탯의 출처별 적용/해제, 처치·흔적·표식 처리. EffectRevision으로 교체 전 재장전 혜택을 무효화한다.
- `Core/StigmaWeaponEffects`: 공통/단계별 데이터에서 원 샷 잔탄 배율·사거리·재장전 혜택을 해석한다. Player에는 개별 성흔 ID 분기를 넣지 않는다.
- `Core/StigmaLinkSkills`: 모듈 ID별 G 행동, 소환체·장판 수명과 대가.
- `UI/StigmaRoomView`, `StigmaTraceView`: 관리 화면과 적 반원 표시.
- `UI/StigmaDescriptions`: 조합 효과·G 효과·대가·단계별 설명 구성. 상세 패널은 현재 페이지의 장착 성흔을 우선 선택하며, 긴 설명은 휠/드래그로 읽는다.
- `Debug/StigmaDebugMenu`: F9 대상별 지급/즉시 지급·장착/레벨, 표식 최대/0, 동전 지급, 탄환 0~6 설정, 원 샷 배율·재장전 속도와 상태 표시. Editor/Development Build만 조작 가능. 하위 보유 없이 강화 지급은 허용하고 강화 보유 후 하위 장착 금지는 유지한다.
- `GameHUD`: `StigmaManager.Changed`의 Reset 이벤트로 관리창 상태를 초기화한다. 조회창의 진입점은 `OpenStigmaManagement` / `CloseStigmaManagement`, 상태는 `StigmaManagementOpen`이다. 성흔방 거래는 계속 Room 서비스가 담당한다.

신규 성흔은 DB 정의 등록, 기존 모듈 조합으로 확장한다. 새 특수 행동은 해당 실행 모듈을 추가한다. BaseDefinition은 획득 선행 조건과 하위 장착 제한의 계보이며 효과를 자동 상속하지 않는다. CommonEffects는 전 단계 공통 효과다. 조합은 정확히 등록된 쌍을 우선하고, UseBaseCombination을 명시한 정의만 하위 계열로 대체해 조회한다. 외부 패시브의 가상체력은 BonusHealth에 별도 source를 등록·지급하도록 연결해야 한다.

## 임시값과 남은 경계

- 기획에서 미정인 범위·상위 단계 시간, 동일 조합 보너스 크기, 연속 처치 창, 개화 재충전량, 사역마 공격 간격·소멸 폭발, 화염 장판 피해는 임시값이다. `StigmaRules.asset` 및 조합 SO에서 조절한다. 동일 조합 보너스 값은 설치 시 조합 SO에 한 번 복사되므로 이후에는 각 조합의 Bonuses도 확인한다.
- 기존 공격은 무기/타격별 기본 피해를 사용한다. G의 백분율 기준은 임시 `LinkBaseAttack=20`에 플레이어 공격력·성흔 공격력·성흔 피해 modifier를 적용한다. 공용 기본 공격력 수치를 기획 확정하면 이 값을 이관한다.
- 기존 Player에 실질적인 피격 경직 타이머가 없어 기본 0.15초를 추가했다. 자연/진흙 경직 보너스가 이 값을 줄인다. 피격감 테스트 대상이다.
- 원본 기획의 시작 시 까마귀 선택 화면은 아직 없다. 현재는 성흔방에서 혼합 카드 최대 3장 중 총 1장을 무료 획득한다. 임시 강화 성흔 플라그라·조건부 카드 획득·새 아이콘은 연결했다. 패시브를 통한 별도 획득 이벤트와 까마귀 고유 효과 재설계는 추가하지 않았다.
- 런 상태이며 게임 종료 후 저장/불러오기는 아직 연결하지 않았다. 인장 판매·퀘스트 동전 보상도 이번 범위 밖이다.
- **RunBuild 완전 삭제 완료.** 옛 잿불 화상, 태그 Fury 버프/표시, 까마귀 옛 스택 추가 피해, 옛 각인 API를 제거했다. 현재 G 화염 장판은 독립 실행 모듈이므로 유지된다. RuntimeSmoke의 옛 스택 검증은 대상별 획득·최소 단계·초기화 검증으로 이관했다. UICommand의 다른 버튼 번호는 그대로 유지했다.
- F9의 적 선택·흔적 강제 부여/제거·체력 수치 입력·전투 이벤트 로그 등 전체 확장 디버거는 아직 제공하지 않는다. 현재 메뉴는 위 사용자 확인 준비에 필요한 장착·단계·표식·동전 조작까지다.

## RunBuild 제거 후 사용자 재확인

1. Play를 종료하고 Main을 다시 열어 시작한다. Missing Script나 컴파일 오류 없이 진입하는지 확인한다.
2. HUD 성흔 아이콘으로 조회창 열기 → ESC 닫기, F9 열기/닫기 → 움직임과 공격이 정상 복귀하는지 확인한다.
3. 성흔방 대상별 획득·무료 교체·강화, 표식 획득과 G 사용을 확인한다. 악마카드 방의 선택 버튼도 한 번 확인한다.
4. 새 런 시작 후 양쪽 성흔·표식·관리창 상태가 초기화되는지 확인한다. 무기 교체 시 폐기된 ‘태그 강화’ 표시가 나타나지 않아야 한다.

이번 제거는 런타임/Editor 컴파일 및 저장 파일의 참조 대조로 확인했다. 새로 끊어진 로컬 참조 없음, 삭제 대상 외 오브젝트 ID 유지, 새 성흔 뷰의 버튼/슬롯 참조 유지, 공용 버튼의 기존 명령 번호 유지까지 확인했으며 Play 테스트는 실행하지 않았다.

## 후속 구현 — 혼합 카드 3택1 및 플레이어 스킬 흔적

사용자의 최종 선택인 **플레이어·까마귀 카드를 섞어 3장 중 1장**을 반영했다. 대상별 한 장씩 지급하던 흐름을 없앴으며, 소유자 배지·카드 선택·확정과 기존 6칸 관리 화면 전환을 프리팹에 저장했다. 후보·획득 기록은 서비스 API에서도 방별로 제한한다. 플레이어 일반 스킬의 흔적 부여와 표식 전환도 공통 전투 경로에 연결했다.

런타임/Editor 컴파일을 통과했다. 기존 TimelineSetup 경고만 남는다. 프리팹의 기존 ID/참조와 새 카드 연결을 정적으로 대조했다. Play·런타임 검증 메뉴는 실행하지 않았으며 위 사용자 테스트 목록이 남아 있다. 까마귀 고유 효과 전면 변경은 이후 별도 작업이다.

설명 UI 사용자 확인: 우무스+아르도르를 장착하면 화재 상시 공격력 보너스, G 대폭발의 범위·피해, 기본 체력 대가와 표식 비용을 읽을 수 있어야 한다. 휠을 내리면 고유 효과와 다음 단계가 보이고, 후보 변경 시 설명이 처음으로 돌아가야 한다. 서로 단계가 다를 때 낮은 단계 설명과 강화 조건도 확인한다.
