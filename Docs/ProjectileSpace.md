# 2.5D 조준과 탄환 판정

작성: 2026-10-31

캐릭터의 이동은 기존 평면 좌표를 사용합니다. 총격의 조준점, 탄환 비행, 몸통 피격 영역과 피격 효과는 화면에 그리는 3D 공간을 사용합니다. 발밑 좌표에 총알이 지나갔다는 이유만으로 피해를 주던 방식을 바꾸었습니다.

## 코드의 역할

- `Assets/Scripts/Combat/CombatBody.cs`: 스프라이트의 크기·기울기·위치로 몸통 피격 상자를 계산하고 총구 위치를 제공합니다. 이미지의 투명 픽셀까지 구분하는 판정은 아닙니다.
- `Assets/Scripts/Combat/ProjectileSpace.cs`: 마우스에서 카메라 방향으로 선을 보내 몸통을 조준합니다. 대상이 없으면 총구 높이의 수평면을 조준합니다. 탄환이 한 프레임 동안 이동한 전체 선분을 검사하여 빠른 탄환이 얇은 벽이나 몸통을 건너뛰는 것을 방지합니다. 회전된 피격 상자를 탄환 반경만큼 확장해 교차를 계산하며 별도의 Rigidbody나 Collider는 요구하지 않습니다.
- `Assets/Scripts/Enemy/Enemy.cs`의 `Bullet`: 실제 3D 위치에서 비행하며 동일한 위치에 탄환을 그립니다. 공통 탄환을 사용하는 발사부도 이에 연결했습니다.
- `Assets/Scripts/Player.cs`: 총의 조준과 발사에 위 좌표를 사용합니다. 관통 사격 역시 몸통을 검사하며, 몸통은 관통하지만 장애물 뒤까지 피해를 주지 않습니다.
- `Assets/Scripts/Combat/WorldShotEffect.cs`: 총격 선과 피격 효과를 실제 3D 지점에 그립니다.

근접 공격, 지면 범위 공격, 올가미 등의 별도 공격은 이 공통 탄환 변경 대상에 포함하지 않습니다. 맵 장애물에 높이 정보가 없으므로 기존 장애물 영역은 모든 높이에서 총격을 막습니다. 낮은 엄폐물 위로 발사하는 기능은 포함하지 않습니다.

## Unity에서 확인하고 조절하기

기본 동작에 수동 연결은 필요 없습니다. `CombatBody`가 없으면 실행 중 자동으로 추가됩니다. 기본 총구는 몸통 중심이므로 실제 그림의 총구와 정확히 맞추려면 아래 설정을 조정해야 합니다.

1. Project에서 `Assets/Editable/Actors/Hunter.prefab`을 열고 `Player`가 붙은 루트 오브젝트를 선택합니다. 다른 캐릭터는 `Enemy`가 붙은 루트를 선택합니다.
2. **Add Component → Combat Body**를 추가합니다. 플레이 중에만 추가/수정한 값은 플레이를 종료하면 사라지므로 프리팹에 저장합니다.
3. Scene 뷰에서 **Gizmos**를 켜고 오브젝트를 선택합니다. 하늘색 상자가 피격 영역, 노란 점이 총구입니다. 자동 영역은 `Sprite Fraction`의 X(가로), Y(세로), `Depth`(두께)로 조절합니다. 기본 비율은 0.7 / 0.8, 두께는 0.5입니다.
4. 기본 총구를 옮기려면 `Muzzle Offset`을 조절합니다. 이 값은 표시 공간의 월드 축 기준으로 X=좌우, Y=높이, Z=맵 앞뒤입니다. 좌우 반전에 따라 자동으로 반전하는 값은 아닙니다.
5. 직접 만든 표시용 외형에 총구 Transform이 있다면 `Muzzle Point`에 연결합니다. 이동용 논리 오브젝트의 XY 좌표를 가진 자식 대신, 화면에 실제로 표시되는 3D 외형의 자식 Transform을 사용해야 합니다. 총구를 벽 너머로 배치하지 않도록 확인합니다.
6. 커스텀 외형에는 몸통 중앙에 빈 오브젝트를 만들고 `Body Anchor`에 연결한 뒤 `Body Size`로 피격 영역의 가로·세로·두께를 지정합니다. 앵커의 회전과 크기도 반영됩니다. 커스텀 외형의 기본 자동 영역은 근사치이므로 직접 확인해야 합니다.

실행 중 자동 생성되는 PaperCard의 표시 오브젝트는 프리팹에 직접 참조를 저장할 수 없습니다. 기본 PaperCard 외형은 자동 피격 영역과 `Muzzle Offset`을 사용하고, 지속적으로 연결할 총구가 필요하면 제작한 표시용 외형에 앵커를 두세요.

## 검증

게임 코드와 Editor 검사 코드의 C# 컴파일을 확인했습니다. Unity 실행 검사는 실행 승인이 취소되어 수행하지 못했습니다.

플레이 모드를 종료한 뒤 메뉴 **Western Lemegeton → Tests → Check Projectile Space**로 준비된 검사를 실행할 수 있습니다. 화면 조준점과 몸통의 일치, 벽 가림, 몸통 위로 지나가는 탄환의 빗나감, 적 탄환의 헌터 판정, 수동 앵커 등을 검사합니다.

실제 플레이에서는 화면 위·아래·좌·우의 적 몸통을 조준하고, 장애물 앞뒤에서 발사하며, 이동 중 총구와 피격 효과가 외형에 맞는지 확인하세요. 런타임 외형과 애니메이션에 따른 최종 위치 조정은 이 플레이 확인이 필요합니다.
