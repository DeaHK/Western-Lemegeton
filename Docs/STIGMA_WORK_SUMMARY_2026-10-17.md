# 성흔 작업 통합 정리 — 2026-10-17

이 문서는 이번 작업 종료 시점의 구현과 최종 규칙을 묶은 인수인계 기록이다. 대화 중 바뀐 규칙은 최종 내용만 적었다. 다음 작업자는 이 문서를 먼저 읽고 [현재 상세 구현·확인 목록](STIGMA_SYSTEM_CURRENT.md)을 참고한다. 실제 코드·저장 에셋이 문서보다 우선한다.

## 1. 작업 결과와 확인 범위

- 성흔 기반, 성흔방 획득·교체·레벨 강화, 대상별 관리 UI, 기본 성흔 효과, 조합 보너스, G 연계스킬 6종, F9 디버그를 연결했다.
- 플레이어 일반 스킬에도 흔적이 붙도록 했다.
- 임시 강화 성흔 **플라그라**를 추가했다. 고유 아이콘, 강화 카드 출현 조건, 하위 장착 제한, 원 샷 피해·쿨타임·재장전 효과를 포함한다.
- 마지막 수정은 **대상 + 성흔 ID별 독립 레벨 저장**이다. 교체 미리보기와 강화 버튼도 함께 수정했다.
- 사용자는 기본 플레이와 카드 흐름이 잘 된다고 보고했고, 마지막에 이번 범위의 작업 종료와 문서 정리를 요청했다.
- 에이전트는 런타임/Editor C# 컴파일과 저장 데이터·참조 정적 점검을 수행했다. 기존 `TimelineSetup.cs`의 obsolete 경고가 남는다.
- **에이전트는 Play·자동 런타임 검증·검증 메뉴를 실행하지 않았다.** 마지막 변경의 모든 수치를 사용자가 개별 검증했다고 단정하지 않는다. 테스트 항목은 아래에 남긴다.
- 이번 정리는 문서 저장까지이며 commit/push는 수행하지 않았다.

## 2. 최종 획득·장착·레벨 규칙

| 항목 | 최종 동작 |
|---|---|
| 소유 구분 | 플레이어·까마귀 획득 목록과 장착 상태를 각각 관리 |
| 관리 UI | 선택한 대상의 성흔을 원형 6칸에 표시, 획득할 때 채움, 7종 이상 페이지 전환 |
| 성흔방 카드 | 플레이어용·까마귀용을 섞은 최대 3장 중 **방 전체에서 1장** 무료 획득 |
| 기보유 제외 | 소유자+성흔 ID 기준. 반대 대상의 같은 종류는 별도 후보 |
| 재방문 | 같은 층·방의 후보와 획득 여부 유지. 닫기/대상 전환으로 재추첨·추가 획득하지 않음 |
| 후보 부족 | 1~2개면 남은 수만 표시, 0개면 관리 화면 이용 |
| 최초 장착 | 해당 대상의 첫 성흔은 자동 장착 |
| 이후 획득 | 다른 계열이면 보관. 현재 장착한 하위 성흔의 강화를 얻으면 강화 성흔으로 자동 교체 |
| 교체 | 전투가 끝난 성흔방에서 보유 성흔끼리 무료 교체 |
| 레벨 저장 | **대상 + 성흔 ID별 독립 저장**. 장착 슬롯 레벨을 다른 성흔에 전달하지 않음 |
| 신규 레벨 | 강화 성흔을 포함해 새로 얻는 성흔은 Lv.1 |
| 레벨 강화 | 현재 장착한 성흔만 강화. Lv.1→2는 400, Lv.2→3은 1000 구리동전 |
| 미장착 선택 | 해당 성흔 자신의 저장 레벨로 미리보기. 강화 버튼은 ‘선택 성흔 장착 후 강화’ 안내 |
| 새 런 | 양쪽 보유 목록·개별 레벨·장착·방 카드 기록 초기화 |

예: 플레이어 플라그라 Lv.3 → 플레이어 로스 Lv.1 → 플라그라 Lv.3으로 복원된다. 로스를 Lv.2로 올리면 이후 로스만 Lv.2이며, 까마귀 로스 Lv.1은 그대로다. 이 저장은 런 내부 상태이며 게임 종료 후 저장/불러오기는 별도 미구현이다.

### 강화 성흔의 획득 제한

- 같은 대상이 하위 성흔을 보유하면 강화 성흔이 일반 무작위 후보 풀에 추가된다. **출현 보장은 없다.**
- 강화 보유 중에는 하위 성흔을 다시 획득하거나 장착할 수 없다. 하위 항목·레벨 기록은 목록에 남고 장착 불가를 표시한다.
- 하위 Lv.3을 장착하다 강화를 얻어도 **새 강화 성흔은 Lv.1**이다. 하위의 레벨을 계승하지 않는다.
- F9에서는 하위 없이 강화 성흔을 즉시 지급·장착할 수 있다. 대상 제한과 하위 장착 금지는 유지한다.

## 3. 효과 적용 단계와 전투 규칙

- 기존 활성화 조건은 양쪽 성흔 장착이다. 한쪽만 장착하면 고유 효과·조합·G는 비활성이다.
- 기본 성흔의 고유 효과와 조합/G는 현재 장착한 양쪽 성흔 중 낮은 레벨을 적용한다.
- **플라그라 고유 효과는 플레이어가 보유한 플라그라 자신의 레벨을 적용한다.** 플레이어 플라그라 Lv.3 + 까마귀 아르도르 Lv.1이면 플라그라 고유 효과 Lv.3, 업화/G Lv.1이다.
- 플레이어 검·총 기본 공격과 일반 스킬 4종, 까마귀 Command 일반 공격이 각자의 흔적을 붙인다. 까마귀 후속타·기존 연계·G·사역마·지속 피해는 제외한다.
- 같은 적의 플레이어/까마귀 흔적 한 쌍을 표식 1개로 전환한다. 현재 적당 1회이며 마지막 일격도 피해 전에 판정한다. 향후 `MaxChargeGrantsPerEnemy=0`으로 반복 허용 가능하다.
- 표식 상한은 G 비용×2. 방·층 이동 시 유지, 사망·새 런 시 초기화. 성흔 교체 시 새 상한까지만 제한하고 부족분을 채우지 않는다.
- 교체/레벨 변경 시 기존 성흔 출처 버프·디버프·가상체력·흔적·사역마·장판을 정리한다. 다른 출처 효과는 보존한다.
- 가상체력 상한은 등록된 부여 효과 중 가장 큰 값이며 초과 누적하지 않는다. 피해는 가상체력부터 소모한다.
- 공격속도·공격력 버프는 합산, 동일 처치 버프는 지속시간 갱신. 감속 하한은 -50%, 감속 대상 받는 피해 +10%는 중복하지 않는다.
- 사역마와 G 화염 장판의 처치는 플레이어에게 귀속된다.

| 성흔 | 대상 | Lv.1 | Lv.2 | Lv.3 |

## 5. 플라그라 추가 효과 — 잔탄 연소

- 원 샷 사거리를 **4→8**로 늘린다.
- 발사 직전 잔탄을 읽어 피해와 쿨타임을 결정한다. 한 발이 관통한 적들은 같은 잔탄 기준 배율을 사용한다.
- 발사 시 잔탄을 모두 소모하고 새 재장전을 시작한다. 0발/빗맞힘에도 동작한다. 발사 전 취소는 소모·추가 혜택이 없다.

### 피해와 쿨타임

피해는 원 샷의 기존 기본 피해에 아래 배율을 곱한다. Lv.1 피해 곡선은 사용자 지정, Lv.2/3은 임시 조율값이다. 쿨감은 모든 단계에서 동일하다.

| 잔탄 | Lv.1 피해 | Lv.2 피해 | Lv.3 피해 | 쿨감 | 기본 8초 기준 쿨타임 |
|---:|---:|---:|---:|---:|---:|
| 0 | 1.1배 | 1.1배 | 1.1배 | 70% | 2.40초 |
| 1 | 1.5배 | 1.6배 | 1.7배 | 58.33% | 3.33초 |
| 2 | 2.0배 | 2.1배 | 2.2배 | 46.67% | 4.27초 |
| 3 | 2.4배 | 2.6배 | 2.8배 | 35% | 5.20초 |
| 4 | 3.0배 | 3.3배 | 3.6배 | 23.33% | 6.13초 |
| 5 | 3.6배 | 4.0배 | 4.5배 | 11.67% | 7.07초 |
| 6 | 4.0배 | 4.5배 | 5.0배 | 0% | 8.00초 |

쿨감은 `0.7 × (1 − 잔탄/6)`으로 선형 보간한다. 표만 반올림하고 내부 계산은 그대로 사용한다. 기존처럼 스킬 종료/취소부터 쿨타임이 시작된다. 발사 전 취소에는 기본 쿨타임을 적용한다. 일반 원 샷과 다른 스킬에는 이 쿨감을 적용하지 않는다.

### 재장전

- 기본 시간은 기존과 같은 **2초**. `Hunter.prefab > Player > Base Reload Seconds`에서 조절한다.
- 일반 자동 재장전은 공속 영향을 받지 않는다. 평타 후 3발 이하 또는 공격에 필요한 탄환 부족 시 시작하는 기존 흐름을 유지한다.
- 강화 원 샷이 시작한 재장전만 현재 플레이어 공속 배율에 비례해 진행한다. 버프 발동/만료가 진행 중에도 반영된다.
- 일정한 공속 1.4배라면 2초÷1.4≈1.43초. HUD/F9는 현재 속도로 환산한 남은 시간을 표시한다.
- 기존 재장전이 거의 끝났더라도 원 샷 발사 시 새 재장전을 시작한다.
- **플라그라 Lv.3: 해당 재장전 완료 시 회피 쿨타임 초기화.** 일반 재장전에는 적용하지 않는다.
- 성흔 교체/레벨 변경/초기화 시 진행 중 재장전의 공속 연동·회피 초기화 혜택을 제거한다. 일반 속도로 재장전은 계속한다. 무기 교체만으로는 재장전을 취소하지 않는다.
- 애니메이션/배속은 이번에 변경하지 않았다.

## 6. 조합/G 연계스킬

| 성흔 조합 | 조합명 / G | 표식 비용 / 상한 | 주요 동작·대가 |
|---|---|---:|---|
| 로스+로스 | 수해 / 범람 | 2 / 4 | 주변 감속. Lv.3 받는 피해 증가. 별도 대가 없음 |
| 우무스+우무스 | 자연 / 개화 | 2 / 4 | 가상체력·가상체력 중 공격력 증가. Lv.3 처치 시 재충전 |
| 아르도르+아르도르 | 업화 / 연소 질주 | 3 / 6 | 양쪽 공속 증가. 종료 후 플레이어 감속 |
| 로스+아르도르 | 증발 / 증기 사역마 | 3 / 6 | 사역마 소환. 유지 중 플레이어 감속 |
| 로스+우무스 | 진흙 / 늪 폭발 | 4 / 8 | 전방 폭발, 감속 적에게 추가 피해. 사용 후 플레이어 감속 |
| 아르도르+우무스 | 화재 / 대폭발 | 5 / 10 | 지정 위치 폭발. 기본 체력에서 최대 체력의 15% 소모, 체력 1 이상 필요 |

플라그라는 명시적 `UseBaseCombination` 설정으로 아르도르 계열 조합을 사용한다. 조합/G 단계는 여전히 양쪽 최소 레벨이다. 별도 G 쿨타임은 없고 행동 중·표식 부족·체력 부족이면 사용을 거절한다.

사용자 요청으로 범위형 G의 반경·사거리를 기존 2배로 확대했다. 현재 Lv.1/2/3 반경은 범람 6/7/8, 늪 폭발 4/5/6, 대폭발·장판 5/6/7이다. 사역마 탐색 거리 14, 소멸 폭발 반경 3, 대폭발 사거리 14, 늪 폭발 전방 거리 4다. 세부 단계 효과와 임시값은 [상세 문서](STIGMA_SYSTEM_CURRENT.md)를 참고한다.

## 7. UI·디버그·아이콘

- 원형 보유 6칸과 혼합 카드 3칸을 별도 화면으로 구성했다. 플레이어/까마귀 상단 탭으로 소유 목록을 전환한다.
- 우측 스크롤에서 현재/장착 시 조합, 상시 보너스, G 효과·대가·표식 비용, 고유 효과와 다음 단계를 읽는다.
- 플라그라처럼 고유 단계와 조합 단계가 다른 경우 둘을 따로 표시한다. 보유 슬롯·F9 목록에도 각 성흔의 저장 레벨을 표시한다.
- F9: 대상별 지급·즉시 지급/장착·레벨 변경, 표식 최대/0, 동전 +2000, 탄환 0~6 설정, 공속·원 샷 배율/사거리/쿨감·재장전 상태 확인. Editor/Development Build용이다.
- 현재 입력: Q 무기 교체, E 첫 스킬(리볼버 원 샷), R 두 번째 스킬, F 성흔방 상호작용, G 성흔 연계스킬, F9 디버그. 예전 설명의 2/3 스킬 키 표기는 현재 입력과 다르다.
- 생성 아이콘: [FlagraIcon.png](../Assets/Resources/Stigmas/Icons/FlagraIcon.png), [생성 프롬프트](FLAGRA_ICON_PROMPT.txt). 이미지 생성 도구로 제작한 RGBA 원본을 저장했다.
- 아이콘이 불꽃 대체 이미지로 나오는 문제를 수정했다. 기존 Combat 폴더 임포터가 일반 Texture로 덮어쓰던 원인이었다. GUID를 유지해 성흔 전용 Icons 폴더로 옮기고 Sprite/Single 임포트 규칙을 추가했다. 이후 사용자 첨부 화면에서 새 아이콘 표시를 확인했다.

신규 성흔은 정의/DB 등록으로 추가한다. 특수 행동은 모듈로 분리하며 Player에 개별 성흔 ID 분기를 추가하지 않는다. `BaseDefinition`은 계보/획득 조건/하위 제한이며 효과를 자동 상속하지 않는다. `CommonEffects`는 전 단계 공통 효과, `UseBaseCombination`은 조합 계승, `OwnerRestriction`은 대상 제한, `UseOwnerLevel`은 개별 고유 효과의 레벨 적용 방식이다.

옛 `RunBuild`는 소스·meta·Main 컴포넌트·옛 UI·호환 API까지 제거했다. UICommand의 다른 저장된 번호와 기존 게임 시스템 연결은 유지했다. `StigmaFoundationSetup`과 기존 검증 코드도 새 구조에 맞춰 갱신했으나 검증 메뉴를 실행하지는 않았다.

## 9. 남겨두는 확인 목록과 범위 밖 작업

사용자가 후속 테스트할 때의 빠른 확인 항목이다. 이 목록을 새 구현 요청으로 해석하지 않는다.

- [ ] 플라그라 3 → 로스 1 → 플라그라 3으로 복원. 로스만 강화해도 플라그라/까마귀 레벨은 유지.
- [ ] 까마귀 Lv.1 상태에서 플레이어 플라그라 Lv.3 고유 효과·회피 초기화 동작, 조합/G는 Lv.1 유지.
- [ ] 잔탄 0/3/6발의 피해와 쿨타임 2.4/5.2/8초, 중간 잔탄 선형 쿨감 확인.
- [ ] 강화 원 샷 재장전만 공속 반영, Lv.3에서 해당 재장전 완료 시만 회피 초기화.
- [ ] 하위 보유 시 강화 후보 추가·출현 비보장, 강화 보유 후 하위 장착 차단, 까마귀 플라그라 제외.
- [ ] 재방문 카드 중복 획득 방지, 무료 교체·400/1000 강화 비용·새 런 초기화 유지.

애니메이션 배속/재장전 모션, 시작 까마귀 성흔 선택, 까마귀 고유 효과 재설계, 추가 강화 성흔, 패시브를 통한 별도 강화 성흔 지급, 게임 종료 후 저장/불러오기는 이번 범위 밖이다. 사용자는 기획자의 후속 설계와 이번 임시 플라그라 작업을 구분했다. 미정 G 세부 수치와 플라그라 Lv.2/3 피해는 테스트 후 조율할 수 있다.
