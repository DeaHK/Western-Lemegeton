# Western Lemegeton — 서부 오컬트 2.5D 프로토타입

Unity 6000.3.17f1. 실행 파일은 `Builds/Windows/Western Lemegeton.exe`이며 데이터 폴더와 DLL을 함께 보관하세요. Unity에서는 `Assets/Scenes/Main.unity`를 엽니다.

## 씬과 작업물 편집

실행 전 Hierarchy에서 배경·문·캐릭터·Canvas를 편집할 수 있습니다. [편집 및 Spine/UI 교체 안내](Assets/Editable/README.md)를 참고하세요. 내보내기 패키지는 `Builds/Packages/WesternLemegeton_Editable.unitypackage`입니다.

## 탐험 구조

히르바 → 동쪽 관문 E → 스테이지 탐험 → 여섯 방 완료 → 06번 방 동쪽 출구 E → 다음 스테이지 선택 순서입니다. 서로 다른 월드 좌표에 저장된 여섯 방의 씬 오브젝트를 사용합니다. 방문 중인 방만 표시하며 나머지 방 객체와 탐험 상태는 유지됩니다.

```text
                            05 풍차 언덕 ─── 06 스테이지 출구 → 다음 스테이지
                                 │
                            03 성흔 제단 ─── 04 악마카드 역참
                                 │
01 붉은 바위 입구 ─── 02 마차 잔해 전투지
```

- 전투방 4곳: 방마다 2~3웨이브. 중간 웨이브 종료 후 2초 준비하며, 모든 웨이브를 처치하면 체력 18 회복 및 연결문 개방.
- 성흔 제단 1곳: 중앙 제단 E → 원형 6노드 UI에서 속성 선택 → 해당 각인 +1. 이번 스테이지에서 한 번 강화합니다.
- 악마카드 방 1곳: 중앙 진열대 E → 세 카드 중 하나 선택. 카드 효과는 이번 런에 누적됩니다.
- 열린 문 근처에서 E를 누르면 연결된 다른 방의 반대쪽 입구로 이동합니다. 되돌아갈 수 있으며 정리한 적이나 보상이 재생성되지 않습니다.
- 성흔/카드 선택을 미루고 다른 방에 갔다가 돌아올 수 있습니다. 선택하지 않은 방은 완료로 계산되지 않습니다.
- **여섯 방을 완료해도 로그 맵은 자동으로 뜨지 않습니다.** 06번 방 동쪽 출구에 접근해 E로 상호작용해야 다음 스테이지를 선택할 수 있습니다.
- M은 현재 여섯 방의 연결·방문·완료 상태와 빌드를 보여 주는 지도입니다. M만 눌러서는 다음 스테이지로 이동할 수 없습니다.
- 마지막 보스도 전멸 후 출구 상호작용을 거쳐 탐험을 완료합니다. 마지막 방을 먼저 정리해도 성흔/카드 방을 빠뜨리면 출구가 잠겨 있습니다.
- 런 전체는 5스테이지, 총 30방(전투 20 + 성흔 5 + 카드 5), 총 50전투 웨이브입니다. 웨이브 수는 런 시드와 방 번호로 정해집니다.
- 방과 스테이지 이동 시 체력·성흔·패시브를 유지하며 새 런에서 초기화합니다.

기존 WNN 원본과 바위길·마차 잔해·제단·풍차·출구 배치를 재사용합니다. 악마카드 방은 현재 무료 선택 방식이며 상점 결제나 재화 가격은 아직 확정하지 않았습니다.

## 그래픽과 카메라

제공된 오브젝트 41개, 기획서의 캐릭터/까마귀 PNG를 사용합니다. 전투 판정은 XY 좌표를 유지하며, 화면은 XZ 지면과 기울어진 스프라이트를 원근 카메라로 표시합니다.

이전보다 가까운 거리 26, 기울기 47도의 카메라에 부드러운 추적과 중심 이동 제한을 적용했습니다. 먼 바위 능선, 중간 절벽, 가까운 선인장·바위로 풍경을 겹치고 먼 층에 약한 시차 이동을 적용합니다. 한쪽의 황금빛 노을, 보랏빛 먼 풍경, 길어진 지면 그림자, 낮은 빛줄기, 속도가 다른 모래 입자와 옅은 먼지층이 분위기를 만듭니다. 지형과 전경은 기존 전투 충돌과 출구 접근을 막지 않도록 배치합니다.

빛과 그림자는 스프라이트 합성 효과이며 실제 태양광/체적 안개 시뮬레이션은 아닙니다. 캐릭터는 셀 애니메이션 포즈 시트를 프레임별로 재생하며 Spine 리깅은 사용하지 않습니다.

## 조작과 전투

| 입력 | 행동 |
|---|---|
| WASD | 달리기, 단검/기술 방향 |
| Shift + WASD | 천천히 걷기 |
| 좌클릭 연속 입력 | 4단계 기본 공격, 리볼버 마우스 조준 |
| Q | 단검/리볼버 태그와 짧은 공격 강화 |
| Space + 이동 | 회피 |
| 2 / 3 | 무기별 기술 |
| 1 | 까마귀 일정 시간 공격 명령 |
| R | 기술·4타 적중 후 6초 이내 수동 연계 |
| E | 연결문 이동 / 제단·카드 선택 / 마지막 출구 지도 |
| M | 로그 맵 확인 / 닫기 |
| Esc | 일시정지 / 돌아가기 |

리볼버는 1/2/1/2 탄약 소비, 3발 사용부터 2초 자동 장전, 장전 중 잔여 탄약 사용 가능. 단검 베어 가르기, 2초 행동 잠금 내려찍기, 직선 원 샷, 주변 난사를 포함합니다. 무기별 기술은 종료 후 8초 재사용 시간입니다.

까마귀는 Follow/Idle/Attack/Return을 기본으로, 동일 적에게 4초 이내 Attack01→02→03→04 적중 시 표식→준비→돌진→도착 피해/전용 효과를 수행합니다. 최대 두 대상, 사망 대상은 활동 반경 내 생존 적으로 대체, 무대상은 표식만 출력합니다.

## 성흔과 패시브

성흔은 수치 갱신, 0.25초 펀치, 임계값에 따른 실제 효과와 테두리 표시를 제공합니다. 우측 하단 성흔 아이콘을 클릭하면 트리 상태를 확인합니다. 성흔과 별도로 패시브 목록·등급 테두리·순차 획득 알림을 제공합니다. 외부 획득 시스템은 `ApplySeongheunStack` / `AcquirePassive`로 연결합니다. [연결 안내](Docs/BuildIntegration.md)에 호출 예시가 있습니다.

성흔은 속성별 활성화·누적 강화를 원형 노드로 보여 줍니다. 첫 노드는 설정 임계값(기본 1), 두 번째 노드는 임계값 +2에 해당하는 강화 이정표입니다. 각인마다 기존 효과가 커지며 두 번째 노드에 별도 미구현 능력을 표시하지 않습니다.

악마카드의 임시 효과는 탄환의 계약=공격력 +8%, 방랑자의 계약=이동 속도 +8%, 검은 날개의 계약=까마귀 공격력 +12%입니다. 희귀는 기본 효과의 1.5배, 레어는 2배이며 같은 효과는 합산합니다. 현재 카드 방의 등급은 1~2스테이지 일반, 3~4 희귀, 5 레어입니다.

성흔 무료 강화 및 카드 효과·등급 배치는 프로토타입 규칙입니다. 드롭 확률·상점 가격, 저장/영구 성장, NPC 대화와 게임패드는 미구현입니다. 스킬은 24개 키 포즈, 이동은 앞·옆·뒤 대각·뒷모습의 32개 포즈와 좌우 반전을 사용합니다.

## 검증

`ProjectSetup.ValidateAndBuild`는 충돌·원본 에셋·콤보·6방 연결 및 재방문 규칙을 검사하고 Windows 빌드를 생성합니다. 실행 인자 `--smoke-test`는 실제 Windows 플레이어에서 30방과 50웨이브를 완료하며 잠긴 문, 전투/서비스 방 전환, 미완료 방을 남긴 출구 차단, 되돌아가기, 중복 보상 방지, M 지도와 출구 상호작용의 차이, 스테이지 간 빌드 유지, 성흔·패시브·까마귀 연계를 검사합니다. 약 2분 후 자동 종료합니다.

결과는 `Logs/runtime-checks.txt`에 기록합니다. 실행 중 원본 캡처는 `Logs`, 최종 미리보기는 `Previews`에 보관합니다.

## 시작 로고
제공된 게임 로고 원본을 Assets/Branding/WnnLogo.png에 보관합니다. 시작 스플래시는 검은 배경의 게임 로고 한 개만 사용하며 Unity 로고는 비활성화합니다. 로고 표시 시간은 2.5초로 설정했고 로딩이 끝나면 기존 타이틀로 이동합니다. ProjectSetup.CreateScene 및 빌드에서도 설정을 다시 적용합니다.

## 황야 오브젝트 비율과 대기 연출

캐릭터 키 1.9를 기준으로 문 전체 높이는 5.2, 마차는 3.5–3.9, 수레는 1.8–2.25, 선인장은 2.4–3.5, 통/상자는 0.9–1.2, 울타리는 1.25–1.7 범위로 맞췄습니다. 원본 종횡비를 유지하고 건물/엄폐물 충돌 폭에도 같은 최종 크기를 사용합니다. 히르바 건물의 간격은 유지합니다.

여섯 방의 실제 문 위치를 기준으로 가장자리 바위·울타리·마른 풀 군락을 배치합니다. 문 양쪽에는 지형을 묶어 두고 중앙에서 문까지 옅은 흙길과 끊어진 바퀴 자국을 연결합니다. 문 앞의 바위가 통행을 가리지 않게 물렸으며, 빈 문 개구부에 서 있을 때 문 전체가 반투명해지지 않습니다. 성흔 방의 예배당은 북쪽 출입구와 겹치지 않도록 서쪽에 배치했습니다. [레벨 배치 기준과 검증](Docs/LevelDressing.md)을 참고하세요.

뒤쪽의 반복 바위 열은 북쪽 문을 비워 둔 불규칙한 바위 무리로 바꿨습니다. 먼 능선은 옅은 보라색과 느린 시차, 가까운 전경은 짙고 큰 실루엣으로 구분합니다. 노을은 황금빛 지면과 옅은 수평 먼지층으로 표현합니다.

접지 표현은 `Assets/Scripts/PropGrounding.cs`에서 관리합니다. 마차와 수레는 이미지 하단 끝 대신 실제 바퀴·상자·부서진 목재의 접촉 지점을 사용합니다. 그 지점을 카메라 시선 방향으로 지면에 투영하여 소프트 팔로우와 Timeline 확대 중에도 접지 그림자가 붙어 있도록 했습니다. 짙고 좁은 접촉 그림자, 짧은 노을 그림자, 눌린 흙·모래 둔덕·작은 돌 조각을 겹치고 바퀴 뒤에 끊어진 짧은 바퀴 자국을 배치했습니다. 화면을 가로지르던 두 직선 자국은 제거했습니다. 접점은 원본 이미지 크롭 영역의 정규화 좌표이며 좌우 반전을 지원합니다.

모래바람·스킬 효과·먼 배경 능선에는 오브젝트용 그림자를 만들지 않습니다. 방을 비활성화하거나 파괴하면 해당 접지 표현도 함께 숨기거나 제거합니다. 지면 장식은 표현용이므로 이동 충돌, 몬스터 배치와 전투 난수에는 영향을 주지 않습니다.

황야에는 넓게 흐르는 먼지층 12개와 가는 모래 입자 82개가 다른 속도로 이동합니다. 바람은 시간에 따라 강약이 바뀌며 플레이어 근처의 먼지는 투명도를 낮춥니다. 걸음과 회피에는 0.4초 이내의 작은 모래 흔적이 생깁니다. 전투 수치나 이동 속도 대신 주변 움직임으로 속도감을 보강한 구성입니다. 원본 PNG를 수정하지 않고 배치·크기·색·합성 연출을 조정했습니다.
큰 바위·선인장·문 뒤에 플레이어나 적이 가려지면 부드럽게 반투명해져 위치와 공격을 확인할 수 있습니다.

## Timeline 연출

던전 입장(2.8초), 플레이어 사망 및 암전(2.7초), 보스 등장(3.4초)을 실제 Unity Timeline 에셋으로 연결했습니다. 입장은 새 스테이지마다 한 번, 보스 등장은 최종 보스 생성 시, 사망은 HP가 0이 되었을 때 재생됩니다. 연출 중 전투는 잠시 멈추고 종료 후 조작을 복원합니다. SPACE/ESC는 건너뛰기, P는 연출 일시정지/계속입니다.

`Assets/Resources/Cinematics`의 `.playable` 파일에서 카메라·동작·이름 표시·암전·소환 문양·효과음 타이밍을 편집할 수 있습니다. [Timeline 연결과 편집 안내](Docs/TimelineIntegration.md)를 참고하세요. 기존 PNG를 변형하는 동작과 임시 효과음을 사용합니다.

## 카툰 스킬 애니메이션

사냥꾼의 네 가지 스킬에 같은 캐릭터의 24개 키 포즈를 연결했습니다. 준비 → 행동 → 타격 → 복귀가 실제 피해 시점에 맞춰 진행되며, 캐릭터 크기는 일정하게 유지하고 베기·총격·착지 이펙트를 따로 재생합니다. 원 샷은 시전 시 조준 방향을 사용하고 기본 공격 역시 준비 동작 이후에 적중합니다. [모션 재생 가이드](Previews/HunterMotionGuide.html)에서 시간별 포즈와 타격 범위를 확인할 수 있습니다. [구성·타이밍·검증 안내](Docs/HunterMotion.md)에 세부 내용이 있습니다.

## 카툰 이동 애니메이션

WASD는 기존 속도로 달리고 Shift를 함께 누르면 절반 속도로 걷습니다. 네 방향 원화와 좌우 반전으로 여덟 이동 방향을 표현하며, 방향마다 대기 1장·보행 루프 6장·정지 1장을 사용합니다. 실제 이동 거리에 맞춰 발동작이 진행되므로 벽에 막히거나 일시정지하면 발동작도 멈춥니다. 공격·스킬·회피가 우선 재생되고 종료 후 이동 동작으로 복귀합니다. 총 조준 방향은 이동 방향과 별도로 유지합니다. [이동 구성과 제작 기록](Docs/Locomotion.md)을 참고하세요.
