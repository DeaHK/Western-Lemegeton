# Logan

보스 분류. 체력 350, 방당 체력 증가 0. 생존 중 체력이 150 이하가 되면 5초 확대 컷신 후 2페이즈로 전환한다. Space/Esc 또는 스킵 버튼으로 종료할 수 있다. 외형·공격 연출은 기존 도형과 Enemy_0 기반 임시 표현이다.

## 코드와 공격 흐름

- `LoganBossAttack.cs`: EnemyBossAttack의 패턴별 설정·사용 토글 구조를 바탕으로 하는 공통 상태 제어와 1페이즈, 컷신.
- `LoganPhaseTwo.cs`: 같은 LoganBossAttack 클래스를 나눈 파일. 2페이즈 설정·우선순위·샷건·채찍·투척 신호를 처리한다. 별도 컴포넌트를 추가하지 않는다.
- `LoganDynamiteVolley.cs`: 한 번에 던진 다이너마이트 묶음의 비행·착지 경고·도화선·중복 피해 방지를 관리한다.
- `EnemyBasicBrain` / `EnemyKeepDistanceMovement`: 거리 유지 이동을 재사용한다. 이동 배율은 0 이상을 허용하여 가속도 처리한다.
- `EnemyHealth`: Base Health 350 / Health Per Room 0.
- `Editor/LoganChecks.cs`: 상태·우선순위·탄환 수·가속·폭발 중복 판정 검사 메뉴.

1페이즈는 총 난사가 준비되고 사거리 안이면 우선 사용하며, 그 외에는 기관총 평타를 쓴다. 기관총 조준 중 총 난사가 준비되면 평타를 취소하고 전환한다. 발사 중에는 전환하지 않으며 발사·후딜 후 다음 패턴을 선택한다.

2페이즈는 채찍 → 다이너마이트 → 샷건 순서다. 근접했고 채찍이 준비되면 채찍을 쓴다. 다이너마이트는 사거리·쿨타임 조건에 더해, 활성화된 다른 2페이즈 스킬인 채찍의 쿨타임이 1초 이상이거나 조준점의 폭발 반경 밖에 Logan이 있을 때 사용한다. 선딜 1초 후 헌터 위치를 다시 확인해 즉시 투척한다. 그 순간 안전 조건을 잃었으면 투척 없이 쿨타임에 들어간다. 조건은 중심 조준점을 기준으로 하므로 흩어진 폭탄의 피해까지 피한다는 보장은 없다.

다른 스킬을 사용할 수 없으면 사거리 안에서 샷건 평타를 쓴다. 샷건 발사 전 다른 스킬 조건이 충족되면 평타를 취소하고 전환한다. 샷건 시작 시 근접하면 먼저 부채꼴로 총을 휘두르며 맞은 헌터를 넉백시키고 0.5초 기절시킨다. 휘두르기 자체의 피해는 없고, 이후 1초 조준한다. 회피·피격 무적 중에는 휘두르기의 제어 효과가 적용되지 않는다. 샷건은 한 번에 7발을 전체 20도 폭으로 발사한다.

채찍은 1초 선딜 후 3초 동안 원형 공격을 한다. 시작 시 1회, 이후 0.5초 간격으로 총 6회(0, 0.5, 1, 1.5, 2, 2.5초) 피해를 판정한다. 지속 피해 경로를 사용하므로 일반 피격/회피 무적 시간으로 주기 피해를 생략하지 않는다. 공격 중 추적 정지 거리는 0으로 바뀌고 종료·취소 시 복원된다.

다이너마이트는 기본 1개 + 추가 2개 = 총 3개를 조준점 주변 원 안의 임의 좌표로 던진다. 각 폭탄은 거리/탄속에 따른 비행 시간으로 포물선을 그린다. 착지 순간부터 원형 폭발 범위를 표시하고 각자 3초 뒤 폭발한다. 같은 묶음은 명중 기록을 공유하므로 서로 다른 시각에 폭발해도 같은 대상에게 최대 1번 피해를 준다. 별도 투척 묶음은 별도로 피해를 줄 수 있다. 헌터·적·Logan 자신·Enemy로 구현된 밧줄을 대상으로 하며, 체력/피격 인터페이스가 없는 까마귀와 배경 오브젝트는 대상이 아니다. 헌터의 일반 피격 무적은 폭발에도 적용된다. 방 전환/초기화 때 폭탄을 정리하고 일시 정지/컷신 중 비행과 도화선은 멈춘다.

## Unity 설정

1. `Assets/Editable/Actors/Logan.prefab`을 열고 루트를 선택한다.
2. **Logan Boss Attack**의 Enable Machine Gun / Barrage / Shotgun / Whip / Dynamite 토글로 패턴 사용 여부를 조절한다. 준비·공격 중인 패턴을 끄면 다음 Tick에 취소된다. 이미 투척된 폭탄은 남는다.
3. **Shotgun**, **Whip**, **Dynamite** 항목을 펼쳐 표의 설정을 변경한다. 채찍 트리거는 공통 **Whip Range**이며 총 난사의 도약·샷건 휘두르기의 근접 경계에도 사용된다.
4. **Phase Two Move Multiplier**가 2페이즈 기본 이동 배율이다. 채찍 사용 중 배율은 **Whip → Slow Fraction**으로 조절한다.
5. 보스로 생성하려면 Main 씬의 Game_Systems → Game Scene Bindings → Enemy Prefabs → Element 3에 Logan을 연결한다. 기존 생성 목록은 자동 교체하지 않는다.
6. 테스트 메뉴는 Western Lemegeton → Tests → Check Logan이다. 플레이 종료 후 실행한다. 코드 컴파일과 Unity 실행 검증은 별개다.

도약은 뒤쪽 경로가 막히면 5도 방향·최대 0.1 거리 간격으로 안전 후보를 검사해 헌터에게서 가장 먼 후보를 택한다. 안전 후보가 없으면 제자리에서 조준한다. 기관총과 총 난사는 조준 종료 지점을 고정해 발사하고, 샷건은 조준 종료 순간의 방향으로 한 번 발사한다. `SignalMachineGun/Barrage/Shotgun/Whip/Dynamite` 메서드를 외부 신호 진입점으로 사용할 수 있다.
## 이동 정지 거리와 공격 사거리

1페이즈 기관총·총 난사 조준 중에는 거리 유지 이동을 한다. 도약 중에는 도약 동작을 수행하며 실제 사격 중에는 정지한다. 이동 설정은 Logan 프리팹 루트의 Enemy Keep Distance Movement에서 조절한다. Use Attack Range를 끄고 Approach Range Factor를 1로 두면 Approach Range가 이동 정지 거리다(현재 4). Retreat Distance는 가까울 때 물러날 거리이며 현재 0으로 후퇴하지 않는다. 공격 사거리는 Logan Boss Attack의 각 Trigger Range에서 따로 정한다. 채찍 공격 중에는 접근·후퇴 거리를 0으로 바꾸어 가속 추적하고 종료·취소 시 저장된 값을 복원한다. 주변 적과의 겹침 방지 이동은 정지 거리 안에서도 생길 수 있다.

Logan은 스킬 실행 중 및 모든 패턴의 후딜 중 다른 패턴으로 전환하지 않는다. 예외적으로 발사 전 평타는 준비된 스킬로 전환할 때 취소한다. 발사 중인 기관총과 후딜 중에는 외부 Signal 메서드도 거절된다. 투척한 다이너마이트의 비행·도화선 및 이미 발사된 탄환은 독립적으로 진행되므로 투척/사격 동작 종료 후 다음 패턴과 함께 남아 있을 수 있다. 사망·비활성화·사용 토글 해제·체력에 따른 페이즈 전환 컷신은 공격 패턴 교체와 별개의 취소 사유다.

### 패턴별 후딜레이

기관총 평타·총 난사·샷건 평타·채찍·다이너마이트 모두 현재 프리팹의 Recovery Seconds는 0.5초다. 조절 가능한 임시값이며 0이면 후딜이 없다. Unity에서 Logan 프리팹 루트 → Logan Boss Attack → 각 패턴 설정 → Recovery Seconds로 변경한다.

발사/채찍 공격/투척 동작이 끝나면 Recovery 상태로 들어가며 이동과 다음 공격을 막는다. 도약 후 조준, 샷건 휘두르기 후 조준은 같은 패턴 내부 단계이므로 그 사이에는 별도 후딜을 넣지 않는다. 다이너마이트 후딜은 투척 동작 직후 시작하며 이미 던진 폭탄의 비행·폭발은 독립적으로 진행한다. 공격 쿨타임은 공격 동작 종료부터 시작해 후딜 중에도 감소하고 후딜 종료 시 재설정하지 않는다. 평타의 발사 전 스킬 전환, 사망·비활성화·페이즈 전환 등 취소는 후딜을 기다리지 않는다. 채찍 가속 및 접근 거리 변경은 후딜 시작 시 복원한다.

### 다이너마이트 회피 도약

Logan은 아직 폭발하지 않은 다이너마이트의 착지 예정 범위와 착지 후 폭발 범위를 감지한다. 자신의 몸 반지름과 안전 여유를 포함한 범위 안이면, 겹친 모든 다이너마이트 범위 밖이면서 벽·장애물을 통과하지 않는 위치로 아치형 도약한다. 다른 Logan이 던진 다이너마이트도 같은 방식으로 감지한다.

도약 거리 이내에서 5도 방향·최대 0.1 거리 간격으로 후보를 검사하고, 안전 후보 중 헌터에게서 가장 먼 지점을 택한다. 안전한 착지점이 없으면 도약하지 않는다. 회피 자체에 무적은 없으며 폭발 전에 범위를 벗어나지 못하면 피해를 받을 수 있다.

회피 중에는 기존 공격/후딜 및 쿨타임을 잠시 멈추고 새 공격 신호를 받지 않는다. 착지 후 기존 상태를 이어간다. 총 난사 도약 도중 회피했다면 회피 착지를 기존 도약의 완료로 처리하고 조준부터 진행한다. 이동 경로에 장애물이 생기면 진행을 멈추며 다음 갱신에서 다시 위험 여부를 판단한다. 사망·비활성화·페이즈 전환 시에는 도약 높이를 복원하고 회피를 취소한다.
